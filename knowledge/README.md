# Knowledge

This directory stores official source catalogs, source metadata, annotation specifications, rule nodes, and coverage gap records approved for public release and version control.

The current Hong Kong FSIE candidate knowledge package is in `hong_kong/fsie/`. It contains a source manifest, candidate rule nodes, evidence requirements, and fictional evaluation cases. All rules remain `unverified` and must not be used for professional conclusions before review by Hong Kong tax experts.

Do not commit client cases, personal information, copyright-restricted full texts, keys, or unapproved raw materials. The `raw/` directory, which may contain restricted content, is excluded by `.gitignore`.
