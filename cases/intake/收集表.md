# 案例收集表（私有案例，K6）

填写说明：只填你确知的；不知道的留空，程序会提问，不会替你补。每一项尽量写明出处文件和页码。金额照原样写，不要缩放：很多门槛是绝对数，缩放可能跨过门槛。公司名一律换成下面的角色名；人名、地址、证件号不要写。

提交前请确认：

- [ ] 案例提供方同意用于本项目的测试与研究；
- [ ] 已脱敏（公司名换成角色名，没有人名、地址、证件号）；
- [ ] 日期如需改动，只做整体平移，且不跨过法律施行日、期限、持股期的门槛。

## D 流（每笔一行）

| 编号 | 付款方 | 收款方 | 种类（股息、利息、特许权使用费、服务费、股权转让、IP 转让、清算、减资） | 金额 | 日期 | 价款是否含增值税 | 预提税、增值税由谁承担 | 出处 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

按种类补充（程序会提示具体字段，名称见 [信息收集.md](../../信息收集.md) 第 3 节）：

- 股息：持股比例与期间、是否上市股份、是否再投资于内地；
- 利息：借款合同利率、同期贷款基准利率、债资比例、是否统借统还；
- 特许权使用费：IP 种类、使用地、是否设备或飞机船舶租赁；
- 服务费：服务在哪里履行、境内天数（12 个月内）、利润率；
- 股权转让：受让方、对价、计税成本、标的公司不动产占比、是否间接转让内地财产；
- IP 转让：价格、IP 种类、计税基础、已获扣除、账面价值与摊销。
