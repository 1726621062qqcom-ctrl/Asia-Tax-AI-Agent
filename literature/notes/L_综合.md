2026-10-14。依据为 `literature/notes/L1–L22`（20 篇有笔记；L8、L15 未取到）、已有卡片 F1、F6–F9、A1、A2、A4、C3 与笔记 J5、J6、J8、J9。方括号内为编号与 PDF 页码；"→"后是对 [测试系统.md](../../测试系统.md) 的结论。本文只记文献能支持或不能支持的点，不替代测试系统.md 本身。

## 1. 文献对各层的共识

```text
预言（§0）    判对错的依据分四类：指定的、推导的、隐含的、无法自动化的人判 [F8 p.2]；差分测试把"两个实现的差异"当候选缺陷，
              差异不等于缺陷，未指定行为也会产生差异 [L1 p.2]；多个实现的多数投票不能代替标准 [L1 p.7]（§0 官方文本是标准）。
核验器（§3.3） 证书 + 比算法简单得多的检查器 [L2 p.4-6, p.28]；检查器必须读未经篡改的原始输入 [L2 p.33-34]；
              证书只证明"这个实例算对了"，不证明候选找得全或最优 [L2 p.34]；整数规划的证书逐步推导、每步写明理由、
              只用精确有理算术 [L3 p.5-7]。
性质证明（A 层）SMT 把"性质的否定"交给求解器，无解即成立，有解返回反例模型 [L4 p.4]；L4 只写了线性算术，没有写判定过程
              的可靠性 [L4 p.4]（L21 p.8 的"可靠"转引自 L4，但 L4 没有这句）。
充分性（§3.5） 变异分数的分母是非等价变异体 [L5 p.4, p.8]；无法编译的变异体是"死产"，不进分母 [L6 p.6]；冗余变异体抬高分数，
              应另报不相交变异体上的分数 [L6 p.9, p.71]；变异体与真实缺陷何时相关尚无定论 [L6 p.81]；
              MC/DC 要求判定中每个原子条件各有一对"只改它、结果跟着变"的用例，一般 n+1 个 [L7 p.15, p.18]，
              耦合条件用遮蔽法 [L7 p.18-19, p.82]，覆盖是充分性度量不是找错方法 [L7 p.61]；覆盖率与检出力相关弱 [J9]。
稳定性（C 层） 不稳定的根因：顺序依赖、随机性、无序集合、时间、IO [L9 p.3-5]；一半顺序依赖来自外部资源 [L9 p.7]；
              原顺序重跑发现不了顺序依赖，随机顺序也可能因"清理者"漏检 [L11 p.7-8]；随机打乱比倒序和有界穷举有效，
              倒序最便宜 [L10 p.8]；结果比较要比"同一失败"而不是通过与否 [L10 p.7]；
              delta debugging 要三值结果（通过/失败/不确定），FAIL 要匹配同一失败，假设改动之间不抵消 [L12 p.6, p.10, p.16]；
              回归选择按动态收集的文件依赖（含哈希与"访问但不存在"的文件），无依赖记录的测试一律全跑 [L13 p.3-4]。
搜索（§3.4）   搜索式测试是带目标函数的有导向搜索，不是随机变换 [L14 p.1-2]；阶梯状地形（高原、标志变量）让随机和爬山失去
              引导 [L14 p.31, p.33]；搜索产生的输入可能在实际中不可能出现 [L14 p.48]；没找到反例不是证明。
论证（§6）     证据没有论证就没有解释 [L16 p.2]；情境和未展开目标要写进结构 [L16 p.2-3]；演绎论证需要"这些就是全部威胁"的
              侧条件 [L17 p.4]；警示项就是未处理的反驳项（削弱型/反驳型）[L17 p.3, p.6]；不建议数值化置信度，汇总用
              最弱环节 [L17 p.3, p.6-7]。
法律代码化近作 大模型只在生成端，判对错靠与独立编写的申报逐格比对 [L18 p.2, p.5]；标准答案本身会错 [L18 p.8]；
              有限基准上的一致不是普遍等价 [L18 p.5]；每表两份输入单元格覆盖 94% 而分支覆盖 44% [L18 p.9]；
              大模型生成的蜕变关系含大量不可靠候选，须专家验证 [L20 p.23, p.27]；有歧义的术语留作输入、不由形式化裁定
              [L22 p.3-4]；两条规则同时改动可使一条永不触发 [L22 p.4-5]；形式化的奖励回路把验证交给确定性内核，
              但内核不能保证形式化忠实于法条 [L21 p.7, p.10, p.14]。
```

## 3. 需要改写或补充的地方

1. **§3.4 结构搜索。** 目标函数 = 候选的保证税额与方案上限之差，邻域 = 加减控股层、移角色、拆流、改债股比、改时点，多次重启并记录种子 [L14 p.1-3]；门槛处给布尔中间量加"离翻转还有多远"的距离，与稳定余量共用数据 [L14 p.31, p.33]；搜索带可落实约束，否则专家包混进不可落实结构 [L14 p.48]；结论写成"N 次搜索、种子 S 下未找到更低结构" [L14；L17 p.9]。
2. **§6 保证论证树。** 节点是命题，不显示通过/警示/失败三态；三态只给叶子检查 [L16 p.5；L17 p.7]。§0 的四个问题写成侧条件节点 [L17 p.4]；"候选空间 = 模板 + N 次搜索"写成情境节点 [L16 p.2-3]；"证明不了下界显示无"对应未展开目标 [L16 p.3]；向上汇总用最弱环节，不引入总分 [L17 p.6-7]。
3. **§4 警示项。** 每条记成反驳项：削弱型还是反驳型、处理状态；专家包里写出，不只显示数字 [L17 p.3, p.6]。
4. **§3.5 变异分数与 `tax_graph/mutation.py`。** 文件头与第 167–168 行把"编译器拒绝变异后的规格"记为 killed，按 L6 应单列"被拒"，不进分母 [L6 p.6]；分母剔除等价变异体，存活者分"已判等价 / 待判 / 真盲区" [L5 p.4, p.8]；PRED、SHIFT 变异体的等价可用 SMT 判定（推断，阶段 6 验证）[L5 p.9]；另报不相交变异体上的分数，需要"变异体 × 用例"杀死矩阵，而现在每个变异体遇首个差异即停 [L6 p.9, p.71]；版本间比较分数要固定用例集 [L6 p.72]；写明杀死判据是"候选上下限、待决组、税项、期限"（介于弱变异与强变异之间）[L5 p.7]；录入错误（漏条、错引条款、整段口径错）不是 NEG/DROP/PRED/SHIFT 能覆盖的，需语义级算子（换引用条款、换基数）。
5. **§3.5 法条覆盖。** 改为"规则条件中的每个原子条件各有一对独立影响税额的测试，至少 n+1 个"，"每个条款至少一个"只作最低一档 [L7 p.15, p.18]；同一事实多处出现、多条规则读同一参数时用遮蔽法 [L7 p.18-19, p.82]；三值逻辑下"未知"同样遮蔽，独立影响要在已知取值上定义（推断）[L7 p.49-51]；加"永不触发的规则"一项，A 层用 SMT 证"每条规则存在可满足输入" [L22 p.4-5]；覆盖只作缺口清单，质量看变异分数 [L7 p.61, p.79；J9]。
6. **§3.3 核验器。** 只读原始案例输入与参数表，不读引擎加工过的中间对象 [L2 p.33-34]；轨迹字段限于能一行算术核对的量，不把计算过程当轨迹 [L2 p.28]；用定点小数或分数，每步写明舍入规则（D37）[L3 p.5]；比较前约定到分的取整，差异先排除口径差 [L1 p.2, p.5]；范围外情形（D30 库外税项、未生效法条）在轨迹里显式标 ⊥ 而不是静默出数 [L2 p.22-24]；核验器与引擎共用参数表，参数错误两边同错，差分抓不到，参数表仍靠 A 层与官方标签 [L1 推断]；核验器通过只证"这个数算对"，最优性另由下界与搜索支撑 [L2 p.34]。
7. **§3.4 下界证书。** 只有数值推导那一步能照 L3 的"逐步推导、每步附理由"写；"该法域在范围内"这类法律事实推理不是线性推断，核验器只能核每步所引参数与算术 [L3 p.5-7]；随机结构搜索不是"候选找得全"的证书 [L3 p.6-7]。
8. **§3.2 蜕变关系。** MR1、MR6 是区间上的单调关系，文献只给点输出，要自己定义 [L19；L20 p.4]；MR5、MR7 的门槛取自参数表而不写死，失败先查 MR 引用的参数年度 [L19 p.6-7]；每条 MR 记成立依据（条款）、已知例外、变异分数下的区分力 [L20 p.27, p.30]；大模型起草的候选 MR 只作草稿，由人对照条文确认 [L20 p.23, p.27]；批量失败时可用决策树给出失败的输入区域，比率条件要用比值特征 [L19 p.8, p.10]。
9. **C 层不稳定检查。** 配置：倒序一次 + 分层随机（模块 → 检查 → 案例）多轮，记录顺序种子 [L11 p.3-4, p.8-9；L10 p.8]；"清空"包括 `official/`、`out/` 等外部状态 [L9 p.7]；失败后按 L11 的方法区分顺序依赖与其他非确定性，分别计数 [L11 p.3-4；L10 p.10]；比较 `status`、`check_id`、`subject`、`measured`，不只看通过 [L10 p.7]；只在基线全通过时运行；固定顺序生成的金标快照不能证明对顺序不敏感 [L10；L11 p.8]；阻断时附失败顺序 [L9；L11]。
10. **C 层变化归因。** 测试函数三值：PASS = 快照一致，FAIL = 同一案例同一税种差额相同，UNRESOLVED = 部分改动下引擎报错 [L12 p.6, p.10, p.13]；改动按口径捆成一个变化，减少 UNRESOLVED；改动可能相互抵消，找到集合后用全集与余集各验一次并标出 [L12 p.16]；排在不稳定项 = 0 之后；失败的电池案例可用 ddmin 缩小后再交人，减少时用领域约束过滤不合法结构。
11. **§5 回归选择。** 在引擎唯一的加载出口记录每个案例读过的文件与哈希（含查询了但无结果的键）作第二路 [L13 p.4]；新增案例或规则、依赖记录缺失时全跑，"快"级不能默默跳过 [L13 p.3]；"全"级不选择；`seconds` 分阶段记收集与分析开销，短套件可能反而变慢 [L13 p.2, p.7]。
12. **§3.1 与 §8b。** 官方标签与 K2 算例分"开发"与"只读保留"两组，避免同一批算例既修引擎又报通过率 [L18 p.2]；算例给出中间步骤时逐步记录 [L18]；标签与引擎不符先查标签出处 [L18 p.8]；§8b 的"一致"写作"在该案例的这些事实与分支下一致" [L18 p.5, p.9]。
13. **A 层 SMT。** "求解器说无解"信任的是实现，L4 没有可靠性论述，对无解结论抽样复核，对有解反例代回引擎确认并入电池（标仅测试用）[L4 p.4]；L4 只支持线性算术，税率变量乘金额须把税率固定为常量 [L4 p.4]；所用 Z3 版本的行为以其文档为准，L4 是 2008 年初版。
14. **判断类事项。** L22（歧义留作输入）与 L21（判断点标出不替裁）支持 DISCRETION 的做法 [L22 p.3-4；L21 p.2, p.10]；反避税条款（一般反滥用、目的测试）标为判断类而非事实 [L22 p.5-7]；口径决定在轨迹里可检索并标出"若口径相反税额变化多少" [L22 p.8]。
