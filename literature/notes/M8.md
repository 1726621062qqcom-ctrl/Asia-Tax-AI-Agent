# M8 Kamath, Jia, Liang, 2020. Selective Question Answering under Domain Shift. ACL 2020, pp. 5684–5696
版本：published；M8_Kamath2020_SelectiveQA.pdf；第 1–9 页全读（设定、方法、实验、误差分析、与不可答问题的关系、讨论），第 12–13 页附录读（特征、离群检测、分域覆盖率），参考文献略过

## 1. 问题与作者主张
- 作者提出"分布偏移下的选择性问答"：模型在域内与域外混合的测试集上，要尽量多回答、同时把已回答部分的准确率保持在高位，不会答对时应当弃答 [p.1]。
- 作者称只用模型 softmax 概率决定弃答（MaxProb）在这一设定下表现差，因为模型在域外输入上过度自信 [p.1-2]。
- 作者的方法是训练一个校准器，预测 QA 模型在给定样例上是否会错，预测会错就弃答；校准器从"已知的域外数据"受益，哪怕那与测试时的域外分布不同 [p.1-2]。
- 作者把"弃答"与"识别不可答问题"区分开：前者是模型若被迫作答会错时弃答，后者是任何系统或人都无法从给定段落推出答案 [p.3]。

## 2. 方法
- 选择性预测：模型输出 (ŷ, c)，置信度 c 低于阈值 γ 即弃答；用风险—覆盖曲线下面积（AUC）和给定准确率下的最大覆盖率评价 [p.3]。
- 三种置信度：MaxProb（最高预测概率）；测试时 dropout（K 个 mask 下的均值或负方差）；校准器（随机森林，七个特征：段落长度、预测答案长度、前五个 softmax 概率），在留出的源域数据与已知域外数据的混合上训练 [p.4-5]。
- 基础模型 BERT-base 在 SQuAD 1.1 上训练 2 轮 [p.5]。

## 3. 数据与设置
- 源域 SQuAD 1.1；五个域外数据集 NewsQA、TriviaQA、SearchQA、HotpotQA、Natural Questions，均取自 MRQA 2019 预处理数据，全部问题可答 [p.5]。
- 每次实验取两个不同的域外数据集分别作已知与未知域外分布，20 种组合取平均；校准集 2,000 例，测试集 4,000 SQuAD + 4,000 未知域外 [p.5]。
- 校准器在 1,600 SQuAD + 1,600 已知域外例上训练，400 + 400 做验证，10 次随机划分取平均 [p.5]。
- 指标：exact match 准确率；AUC 越低越好，80% / 90% 准确率下的覆盖率越高越好 [p.5]。

## 4. 结果
- 表 1：MaxProb AUC 20.54、80% 准确率下覆盖 48.23%、90% 下 21.07%；只用源域训练的校准器 19.27 / 53.67 / 26.68；源域加已知域外训练的校准器 18.47 / 56.06 / 29.42；最优可能 9.64 / 74.92 / 66.59；把已知域外数据加进 QA 训练再用 MaxProb 为 19.61 / 51.75 / 22.76 [p.6]。
- 表 2：测试时 dropout 的负方差作为置信度很差（AUC 28.13），均值可用（18.35）；带 dropout 特征的校准器最好（17.31 / 59.99 / 34.99），但 K 倍运行开销 [p.6]。
- 表 3：模型在 SQuAD 约 80.95，在多数域外集约 40%–50%，SearchQA 仅 17.98；用 2,000 条已知域外数据训练对其他未知域外集一般无助 [p.7]。
- MaxProb 域内偏保守、域外过度自信：MaxProb 为 0.6 时，SQuAD 问题约 80% 答对，域外问题约 45% 答对 [p.7]。
- 表 4：去掉全部 softmax 概率特征后 AUC 由 18.47 升到 26.41、80% 覆盖由 56.06 跌到 24.57；去掉段落长度 AUC 19.79、覆盖 51.73 [p.8]。
- 误差分析（NewsQA→TriviaQA）：62% 的"过度自信"错误其实是等价答案或片段边界不一致；45% 的"过度保守"错误源于长距离共指，25% 源于段落证据不足 [p.8]。
- 与不可答问题的关系：用 SQuAD 2.0 训练的模型，校准器 AUC 18.38，与 SQuAD 1.1 的 18.47 几乎相同；用置信度阈值识别不可答问题只有 54.0 EM（MaxProb 53.1），仅略高于多数类基线 48.9 [p.8-9]。
- 混合比例：测试集全为域内或全为域外时校准器与 MaxProb 差距接近 0，混合时校准器明显更好 [p.9]。
- 附录 A.3：用离群检测器做选择性预测很差（AUC 24.23，80% 准确率下覆盖 37.91%）[p.12]。

## 5. 作者陈述的局限
- 若能拿到未知域外分布的样本，结论不成立：在其上训练 QA 模型加 MaxProb 的 AUC 16.35 优于校准器的 17.87 [p.9]。
- 所有方法都远差于最优选择性预测器，但达到该上界可能不现实 [p.5-6]。
- 问题长度、段落与问题的词重叠作为特征没有改善验证表现 [p.12]。
- 其余未专门讨论。

## 6. 原文摘录
- "Abstention policies based solely on the model's softmax probabilities fare poorly, since models are overconfident on out-of-domain inputs." [p.1]
- "In these cases, the goal is to "abstain" when no system (or person) could infer an answer to the given question using the given passage. In contrast, in selective prediction, the model should abstain when it would give a wrong answer if forced to make a prediction." [p.3]
- "This demonstrates that training a calibrator is a better use of known OOD data than training a QA model." [p.5]
- "the model is about 80% likely to get the question correct if it came from SQuAD (in-domain), and 45% likely to get the question correct if it was OOD." [p.7]
- "Taken together, these results indicate that identifying unanswerable questions is a very different task from knowing when to abstain under distribution shift." [p.9]

## 7. 对本库的可用点（笔记者推断）
- 本文把两件事分开：问题本身不可答（文档没说）与模型会答错（文档说了但读错）。本库的"缺失"只覆盖前者；第 3 轮评测里剩下的 4 处错都是后者。本文的答案是一个独立于抽取器的校准器：拿已知会错的样本训练一个"这次会不会错"的分类器。本库没有 softmax，可用的特征是程序能算的：字段类型、候选段落数、两遍是否一致、引文长度、值在文档中出现几次、段落与字段释义的检索分、文档里同一量有几个不同数字。十案例的逐字段对错记录就是训练集（约 170 条），可先做规则阈值再做分类器。
- 本文显示域外时概率过度自信，而本库的真实案例对模型来说就是"域外"（港交所通函、招股书）；用模型自报的置信度做弃答依据不可靠，程序侧特征更稳。
- 本文的覆盖率—准确率曲线是评测抽取改造的合适形式：改造的目标不是正确读出最多，而是在"落入案例的值错误率低于某阈值"的约束下覆盖最多，其余退回问题单。
