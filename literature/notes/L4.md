# L4 de Moura, Bjørner, 2008. Z3: An Efficient SMT Solver. TACAS 2008, LNCS 4963, 337–340
版本：published（出版社版）；L4_deMoura2008_Z3.pdf；全文（第 1–4 页，参考文献略读）。本文是 4 页的工具描述，不含实验、形式化证明或正确性论证

## 1. 问题与作者主张
- 作者说明 SMT（可满足性模理论）是对带算术、位向量、数组、未解释函数等背景理论的一阶公式的判定问题 [p.1]。
- 作者称 Z3 是微软研究院的新型高效 SMT 求解器，面向软件验证与软件分析中的问题，并集成了多种理论 [p.1]。
- 作者称 Z3 使用了量词实例化和理论组合的新算法 [p.1]。

## 2. 方法
- 输入经过：简化器（不完备但高效的代数化简和有限的上下文化简）、编译器（转成子句与同余闭包节点）、同余闭包核心（E-图）、SAT 求解器与各理论求解器 [p.2-3]。
- SAT 求解器：两观察文字、冲突子句学习、相位缓存、非时序回溯；布尔分裂由它控制 [p.3]。
- 理论组合：用一种新的方法，增量地协调各理论维护的模型 [p.3]。
- 量词：通过 E-图上的 E-matching 实例化；子句删除与相关性传播用于减少无用原子 [p.3-4]。
- 理论求解器：线性算术求解器基于 Yices 所用算法；数组理论用延迟实例化；定长位向量除等式外全部位爆破 [p.4]。
- 模型生成：Z3 可在输出中给出模型，为输入中的常量赋值并给出谓词、函数符号的部分函数图 [p.4]。
- 接口：文本格式（SMT-LIB、Simplify、原生格式）与 C、.NET、OCaml 的 API [p.1]。

## 3. 数据与设置
- 工具描述，没有数据集、基线或评测指标。唯一的性能陈述是 Z3 原型参加了 SMT-COMP'07，得 4 个第一名、7 个第二名 [p.1]。
- 客户端：Spec#/Boogie（2007 年 5 月起以 Z3 取代 Simplify 作为默认推理引擎，作者称定理证明性能大幅提升）和 Pex（用 Z3 生成不同行为的测试用例）；另列 HAVOC、Vigilante、VCC、Yogi，SLAM/SDV 在整合中 [p.1-2]。

## 4. 结果
- 无独立的实验结果节。作者仅陈述：SMT-COMP'07 的名次（见上）[p.1]；Spec# 换用 Z3 后的性能改进（未给数字）[p.2]；E-matching 的新算法"实验结果显示相对现有最先进的 SMT 求解器有显著性能提升"，指向另一篇文献 [p.4]。
- Z3 自 2007 年 2 月起在微软若干项目中使用，主要应用为扩展静态检查、测试用例生成与谓词抽象 [p.4]。

## 5. 作者陈述的局限
- 文中未专门讨论局限。作者仅说明简化器是不完备的（"incomplete, but efficient"）[p.3]。文中没有关于判定过程可靠性（soundness）的陈述，也没有说明是否输出不可满足性证明。

## 6. 原文摘录
- "An SMT solver is a tool for deciding the satisﬁability (or dually the validity) of formulas in these theories." [p.1]
- "Z3 is a new SMT solver from Microsoft Research." [p.1]
- "Z3 uses a linear arithmetic solver based on the algorithm used in Yices [9]." [p.4]
- "Z3 has the ability to produce models as part of the output." [p.4]
- "Input formulas are ﬁrst processed using an incomplete, but eﬃcient simpliﬁcation." [p.3]
- "Z3 is being used in several projects at Microsoft since February 2007." [p.4]

## 7. 对本库的可用点（笔记者推断）
- 阶段 6 / A 层 SMT 性质证明："抵免不超过税额""无销项不抵扣""协定限率不高于国内税率"这类全输入性质，可写成约束的否定交给 Z3：无解则性质成立，有解则返回的模型就是反例（论文 p.4 的模型生成能力）。这一做法在 L21（p.7）中也作为内核步骤出现。
- 论文只写了线性算术求解器（p.4），没有说明非线性（税率变量乘税基）的支持。本库的性质若涉及税率与金额的乘积，需要固定税率为常量使之线性，或另查后续版本的文献；本论文不能支持非线性结论。
- 可靠性依赖：本文没有给出判定过程可靠性的论述，也没有提到证明输出。A 层把"求解器说无解"当作性质成立的依据时，信任的是求解器实现。L21 的 p.8 称 Z3 对无量词线性整数、实数算术的判定过程是可靠的，并以本文为引用，但本文并没有这样写；该可靠性主张需要另找来源，或要求核验"反例路径"（有解时用引擎实际代入反例，确认确为违反）与对"无解"的结果做抽样复核。
- 模型输出用于 A 层：反例模型可直接转为案例输入，送进引擎复算，作为"性质被违反"的可执行证据，并可纳入电池案例（标为仅测试用）。
- 版本说明：本文是 2008 年的初版描述；本库将使用的 Z3 版本远新于此，具体行为（如非线性算术、字符串、优化）以所用版本的文档为准，本文不可作为依据。
- 不适用：Pex 与 Spec# 的用法（程序验证条件、符号执行）不是本库的用法；本库只需公式小、无量词的规则条件。
