# notes：第 I、J、K、L 轮阅读笔记

2026-10-08 起。第 I 轮服务于官方库（`official/`）的改造，第 J 轮服务于三类问题（分析低效、局部最优、数据库使用不精确）的优化方案。第 K 轮（2026-10-11 起）服务于案例采集（[案例采集.md](../../案例采集.md)）：判例因素与先例约束。第 L 轮（2026-10-14 起）服务于测试系统（[测试系统.md](../../测试系统.md)）：测试预言、蜕变关系、可证明算法与证书、SMT、变异与覆盖充分性、不稳定测试与回归选择、搜索式测试、保证论证，以及税法代码化近作；综合见 `L_综合.md`。第 M 轮（2026-10-14 起）服务于抽取边界的改造（[抽取改造.md](../../抽取改造.md)）：指南式抽取、长上下文位置效应、采样一致性与语义熵、弃答与校准、知识冲突与矛盾证据、合同级 NLI、数据清洗的约束与外部字典、长文档关键信息抽取、不可答问题、语法约束解码；综合见 `M_综合.md`。论文文件在 `literature/` 下以 `I*_`、`J*_`、`K*_`、`L*_` 开头，文本在 `_work/text/<ID>.txt`（`=== [p.N] ===` 为 PDF 第 N 页），取得方式记在 `_work/round_index.json`。

## 笔记结构

```text
# <ID> 作者, 年份. 题目. 出处
版本：published | author | preprint；文件名；阅读范围（全文 / 哪些页）

## 1. 问题与作者主张      2–5 条，归属作者
## 2. 方法                写到能看懂结果为止
## 3. 数据与设置          数据、规模、语言、基线、评测指标
## 4. 结果                每条带 [p.N]；数字照抄；正负结果都写
## 5. 作者陈述的局限      带页码；没有写"文中未专门讨论"
## 6. 原文摘录            4–6 条逐字引文：- "原文" [p.N]
## 7. 对本库的可用点（笔记者推断）
                          与第 1–6 节分开；每条说清对应库的哪一层，并写不适用或冲突之处
```

第 1–6 节只转述论文，不评价；第 7 节是推断，单列。`python literature/tools/check_notes.py` 核对每条引文在所标页（前后各放宽一页）逐字出现、页码不越界。
