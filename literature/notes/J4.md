# J4 Sanner & McAllester, 2005. Affine Algebraic Decision Diagrams (AADDs) and their Application to Structured Probabilistic Inference. IJCAI 2005
版本：published；J4_Sanner2005_AADD.pdf；第 1–7 页全读（含参考文献）

## 1. 问题与作者主张
- 作者指出 ADD 把函数 Bn → R 表示为带实数终端节点的有向无环图，并在固定变量序下给出最小的规范（canonical）形式；ADD 对合取、析取型的 context-specific independence 紧凑，但对加性或乘性结构会指数膨胀（作者用 f = 4a + 2b + c 的例子说明）[p.1]。
- 作者提出 AADD：在边上带 affine 变换 ⟨c, b⟩，能规范且紧凑地表示 context-specific、additive、multiplicative 结构 [p.1]。
- 作者主张 AADD 的最坏时间与空间在 ADD 的常数倍之内，而在某些情形下对变量数是线性的，此时 ADD 是指数的 [p.1]。
- 作者说明目的不是证明 AADD 版的 variable elimination 与 value iteration 是最佳的推理算法，而是证明透明替换表示即可带来指数级改进 [p.7]。

## 2. 方法
- 语法：G ::= c + bF；F ::= 0 | if(Fvar, ch + bhFh, cl + blFl)；ch、cl 在 [0,1]，bh、bl 在 (0,1]；约束：Fvar 不在子图中重复出现；min(ch, cl) = 0；max(ch + bh, cl + bl) = 1；F = 0 时 b = 0，否则 b > 0 [p.1-2]。
- Lemma 2.1：规范化 AADD 的值在 [0,1]，最小值为 0，非 0 时最大值为 1。Lemma 2.2：固定变量序下，任一非常数函数 Bn → R 有唯一的广义 AADD 表示（规范性）[p.2]。
- GetGNode：若高低分支相同则返回子节点；否则用 rmin、rmax 把边权规范化到 [0,1]，在节点缓存中查找或新建 [p.3]。Reduce 对任意有序 AADD 规范化并缓存内部节点，无需预先指定要利用的结构 [p.2-3]。
- Apply：先用 ComputeResult 检查能否不递归直接算出（如 ⟨3 + 4F1⟩ ⊕ ⟨5 + 6F1⟩ 直接得 ⟨8 + 10F1⟩）；否则用规范化的 cache key 查缓存，再选变量递归并把 affine 变换下推到分支 [p.3]。
- Canonical caching：缓存条目归一化，使 ⟨0+1F1⟩ ⊕ ⟨0+2F2⟩ 的结果可复用于 ⟨5+2F1⟩ ⊕ ⟨4+4F2⟩ = ⟨(2cr + 9) + 2brFr⟩，作者称这使 Apply 缓存得到最优复用，相对非规范缓存可使时间指数下降 [p.4]。
- 其他操作：节点 ⟨c + bF⟩ 的 min 与 max 分别为 c 与 c + b；restriction 返回含该变量的节点的相应分支；sum out 为两个 restriction 之和；取负与取倒数须显式做（0 ⊖ ⟨c+bF⟩）；变量重排可推广 Rudell 算法 [p.4]。
- max/min 的 ComputeResult 剪枝：c1 + b1 ≤ c2 时 max 返回第二个操作数；同一 F 且 (c1 ≥ c2 ∧ b1 ≥ b2) 时 max 返回第一个操作数（min 取相反）[p.5]。
- 数值缓存：浮点精度会令本应相同的节点偏差约 ±1e-15，作者用容差 ϵ 的近似哈希（距原点 L2 距离分桶），取 ϵ = 1e-9 [p.4-5]。

## 3. 数据与设置
- 基本操作：对 Σ 2^i x_i 的加、γ^(Σ 2^i x_i) 的乘、Σ 2^i x_i 的 max，比较 table、ADD、AADD，变量数 6–18 [p.6]。
- Bayes net：variable elimination（固定的贪心 treewidth 最小化顺序），对 Alarm、Barley、Carpo、Hailfinder、Insurance 及两个 15 个父节点的 noisy-or / noisy-max CPT 各跑 100 个随机查询（一个查询变量、一个证据变量）[p.6]。
- MDP：value iteration，SysAdmin 域的 star、bidirectional ring、independent rings 配置，收敛到最优值 0.01 内 [p.6-7]。

## 4. 结果
- Theorem 5.1：Reduce 与 Apply 的时间与空间最坏情况在 ADD 的常数倍内；理由是 ADD 等价于固定 c = 0、b = 1 的非规范 AADD，规范化只会增加缓存命中 [p.5-6]。
- Theorem 5.2：存在 F1、F2 与 op，使 AADD 的 Apply 对变量数线性而 ADD 指数；例子为 Σ 2^i x_i ⊕ Σ 2^i x_i 与 ∏ γ^(2^i x_i) ⊗ ∏ γ^(2^i x_i)；AADD 产生 n 个缓存节点与 2n 次 Apply 调用 [p.6]。
- 基本操作实验（Figure 5，含 max）显示 AADD 的时间与空间对变量数线性 [p.6]。
- Table 2（Bayes net，节点数 / 运行时间）：Alarm 表 1,192 / 2.97 s，ADD 689 / 2.42 s，AADD 405 / 1.26 s；Hailfinder 表 9045 / 26.4 s，ADD 4511 / 9.6 s，AADD 2538 / 2.7 s；Insurance 表 2104 / 278 s，ADD 1596 / 116 s，AADD 775 / 37 s [p.7]。
- 负面或持平的结果：Carpo 上 ADD 955 节点多于表的 636 条；Noisy-Or-15 上 ADD 125356 节点多于表的 65566 条，运行 50.2 s 对表的 27.5 s；Noisy-Max-15 上 ADD 202148 对表 131102，运行 42.5 s 对 33.4 s [p.7]。
- Noisy-Or-15：AADD 1066 节点、0.7 s；作者称相对其他表示为指数到线性的缩减；Noisy-Max-15：AADD 40994 节点、5.8 s [p.6-7]。Barley 上表与 ADD 超出 1Gb 内存限制（EML），AADD 为 60,809 节点、207 m [p.7]。
- MDP：作者称精确 value function 中 AADD 的大小仍是指数的（对所有表示均如此），说明精确值函数里几乎不剩加性结构，但 AADD 在计算过程中仍利用了加性结构，表现与 ADD 和表相当或指数级更好 [p.7]。

## 5. 作者陈述的局限
- 作者说明 *BMDs、EVBDDs 等相关结构因整数终端需要有理数或浮点表示，在其经验中因精度误差与计算困难而不适于概率推理 [p.2]。
- 作者说明 Apply 算法若假设可交换，则不能用于 ⊖ 与 ⊘，需改为在任一操作数上递归 [p.3]。
- 浮点缓存的近似哈希不保证容差内的 4 元组落入同一桶（可能跨桶边界）[p.5]。
- 作者称空间所限未能涵盖 AADD 可高效执行的全部操作，亦未讨论与相关数据结构的全部差异 [p.2, p.4]。
- 其余局限：文中未设专门的 Limitations 一节。

## 6. 原文摘录
- "ADDs enforce a strict variable ordering on the decisions from the root to the terminal node, enabling a minimal, canonical diagram to be produced for a given function." [p.1]
- "the compactness of ADDs does not extend to the case of additive or multiplicative independence" [p.1]
- "The min and max of a generalized AADD node ⟨c + bF⟩ are respectively c and c + b due to [0, 1] normalization of F." [p.4]
- "normalization can only increase the number of Reduce and Apply cache hits and reduce the number of cached nodes" [p.6]
- "the exponential size of the AADD (as for all representations) indicates that little additive structure survives in the exact value function." [p.7]
- "it is better to use a hashing scheme that considers equality within some range of numerical precision error" [p.4]

## 7. 对本库的可用点（笔记者推断）
- 联合代价与精确 min/max（层：局部最优）：把一个候选结构的税额写成待定条件（布尔变量）的函数 tax(x1..xn)，AADD 可存下这个完整函数，min 与 max 在根节点读出为 c 与 c + b（常数时间，[p.4]）。这样 floor 与 ceiling 来自同一个对象，而不是对"全有利"和"全不利"分别重跑；联合代价（同时强制多个待定项）是对该函数的 restriction，不需逐个重算整图。
- 增量与记忆化（层：分析低效）：Apply 的 canonical caching 与 restriction 对应本库"强制某待定项另一种取值后重算整图"：restriction 是对已建函数的局部操作 [p.4]，无需重新评估所有 flow。但前提是每条 flow 的税额已写成关于待定变量的函数，这要求规则层输出的是符号函数而非单点数值。
- 加性结构的契合：多条 flow 的税额按候选结构相加，每条 flow 只依赖少数待定变量；加法 ⊕ 在 AADD 上是 Apply，若各 flow 依赖的变量不同，节点数可远小于全表（论文 Theorem 5.2 与 Table 2 的 Noisy-Or 例子）。"相关性判定需枚举至多 2^7 组合"可替换为在函数上检查某变量是否出现于规范图（规范性 Lemma 2.2 保证无关变量不出现）[p.2]。
- 不适用或冲突：(1) 税额里的 min/取大、阈值、分段税率、抵免上限等是分段非线性操作，AADD 对 max/min 是支持的（Apply），但论文未评估这类函数的规模；MDP 实验显示精确值函数中加性结构几乎消失 [p.7]，本库的税额函数是否保留加性结构要靠实测。(2) 论文值域是 [0,1] 内的浮点并依赖容差哈希 [p.4-5]；本库要求逐位可追溯的数额，应换成精确有理数/定点数，并放弃容差哈希。(3) 变量序影响规模，论文以固定贪心序运行，Barley 上 AADD 仍需 207 m [p.7]。(4) 待定条件的三值（true/false/pending）语义在论文里没有对应，须自行编码为两个布尔量或把 pending 作为变量。
