# M 轮综合：抽取边界的文献核对

2026-10-14。依据为 `literature/notes/M1–M16`（16 篇，全部取到：13 篇出版版，M9、M13 用预印本）。方括号内为编号与 PDF 页码；"→"后是对 [抽取改造.md](../../抽取改造.md) 的结论。本文只记文献能支持或不能支持的点，不替代抽取改造.md 本身。

## 1. 文献对各层的共识

```text
模型读什么          指南（定义 + 代表性例子 + 例外）决定零样本抽取的上限，例子比定义更有用 [M1 p.8]；标签名的强先验
                    会压过指南 [M1 p.3]；提示措辞与示例选择一字之差有 9–15 F1 之别 [M12 p.5]。
                    → 释义加例子，提示当代码管理，改动即重测。
模型在长文里找      相关信息在中间时表现 U 形下降，扩展上下文的模型未必更会用 [M3 p.1, p.6]；阅读器远早于检索器饱和
                    [M3 p.10]；文档越长越差 [M13 p.12]；检索召回高时模型只读不记 [M16 p.5]。
                    → 定位改为检索候选段落，少给、靠前、字段清单前后各放一次。
模型记还是读        数值与日期最靠记忆 [M11 p.7-8]；抽取式阅读器几乎不记 [M11 p.7]；语法约束把输出限制到输入里的候选
                    [M15 p.7, p.9]。
                    → 数值、日期由程序从引文解析，模型只定位；引文里没有的数不是值。
采样一致性          多样本一致性与正确率高度相关 [M9 p.8]；语义熵按意义聚类、离散变体只需黑盒输出 [M10 p.3, p.8]；
                    一致性抓"任意错"不抓"系统错" [M10 p.1, p.5]；有参考文本时 NLI 变体更强 [M2 p.8]。
                    → 两遍一致只是辅助防线；比较前先按单位、粒度归一；系统性误读靠释义与程序核对。
冲突                多段落矛盾时模型按先验、顺序、数量、长度选边 [M7 p.8-9, p.15]；置信度不反映冲突 [M16 p.6-7]；
                    模型只依一段 [M4 p.7]；要求检测矛盾时在无矛盾处会编造 [M4 p.9]；否定、情态扰动被无视 [M16 p.7]。
                    → 冲突识别只能是程序比值：各段单独读，值不同即冲突，两值连引文报人；布尔字段按蕴含 / 矛盾 / 未提及读。
弃答与校准          不可答 ≠ 会答错 [M8 p.3]；softmax 域外过度自信，独立校准器更好 [M8 p.1, p.7]；似是而非的答案对人和机器
                    都有效 [M14 p.5]；自动生成的负例太容易 [M14 p.5]；弃答只把错答换成不答 [M11 p.5]。
                    → 校准器用程序能算的特征；评测按覆盖率—错误率曲线报；人写的"缺失"标注不可被蜕变测试替代。
检测与修复          修复的上限由检测决定 [M6 p.11]；约束、外部字典、统计是三类检测信号 [M6 p.2]；外部字典收益看覆盖
                    [M6 p.10]；登记簿与文档之间 5%–9% 错误、13%–63% 轻微差异 [M13 p.7]；零样本错误检测几乎无效 [M12 p.4]。
                    → 一致性检查用否定约束、登记簿交叉用匹配依赖，都由程序做；不问模型"这个值错没错"。
证据粒度            整句、可独立理解的片段才是给人核对的证据 [M5 p.2]；以例外作否定可相隔数页 [M5 p.7]；
                    找对证据判断就大幅变好 [M5 p.7]。
                    → 引文以句或列表项为单位；同一字段的候选段落一起考虑，召回比读取精巧更值钱。
```

## 3. 需要改写或补充的地方

- 抽取改造.md §0 把"两遍一致"写成主防线之一，文献（M10 p.1、M2 p.7）说它只抓任意错；改为"辅助防线"，主防线是释义、程序解析、冲突检测。
- 信息收集.md §8 的表里"说错但引文是真的"一行只写了两遍读取与守则，应补"数值、日期由程序从引文解析"与"各段单读报冲突"。
- 读取提示把字段清单只放在文档前面；按 M3 应前后各放一次（定位提示）。
- 适配器未设温度；按 M9 两遍一致需要采样多样性，温度要显式设并记入评测记录。
- field_gloss.csv 缺"原文怎么说"一列；按 M1 例子比定义更有用，可从已有案例的出处行自动抽取。
- 评测报告只报对错总数；按 M14 的负例分类和 M4 的冲突四维，分类报错填与冲突。
