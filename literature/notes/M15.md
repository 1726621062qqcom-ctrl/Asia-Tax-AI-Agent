# M15 Geng, Josifoski, Peyrard, West, 2023. Grammar-Constrained Decoding for Structured NLP Tasks without Finetuning. EMNLP 2023, pp. 10932–10952
版本：published；M15_Geng2023_GrammarConstrainedDecoding.pdf；第 1–10 页全读（方法、三项任务的设置与结果、延迟、似然错位、相关工作、最佳实践、局限），附录（微调对比、提示、解码设置、示例）与参考文献略过

## 1. 问题与作者主张
- 大语言模型未经微调时不能可靠地生成复杂的结构化输出；语法约束解码（GCD）在解码时只允许符合形式语法的 token，保证输出结构合法 [p.1]。
- 作者主张形式语法能描述远比解析、代码生成更广的任务的输出空间，GCD 可作结构化 NLP 任务的统一框架；并提出"依赖输入的语法"，使输出空间随输入变化（如实体消歧的候选集、成分句法树的叶子）[p.1-2]。
- 作者称语法约束的模型大幅优于无约束模型，在封闭信息抽取与实体消歧上甚至可比肩或超过为该任务微调的模型 [p.1, p.6]。
- 作者明说：API 型服务不暴露词表分布，不能用 GCD [p.4, p.10]。

## 2. 方法
- 用户写字符级语法 G，经分词器转成 token 级语法；增量解析器（Grammatical Framework）充当补全引擎，在每一步给出允许的下一 token 集合，用它剪枝模型的分布；与贪心、beam、top-k 等解码兼容 [p.3-4]。
- 图 2 列出 14 个任务的语法，13 个依赖输入 [p.3]。
- 与少样本提示结合：不微调，只在生成时加约束 [p.4]。
- 对实体消歧比较依赖输入的语法（IDG，候选集只含该提及的候选）与不依赖输入的语法（IIG，全部 47 万实体）[p.5]。

## 3. 数据与设置
- 封闭信息抽取：SynthIE-text 测试集，实体 270 万、关系 888（Wikidata），4-shot，指标三元组微平均 P / R / F1 [p.4-5]。
- 实体消歧：AIDA-CoNLL、MSNBC、ACE2004、AQUAINT、CLUEWEB、WIKI，微准确率 [p.5]。
- 成分句法分析：Penn Treebank 测试集中金标树短于 64 token 的句子，8-shot，bracketing F1 与树的合法率 [p.6]。
- 模型：LLaMA-7B / 13B / 33B、Vicuna-7B / 13B，不做任何下游微调 [p.6]。

## 4. 结果
- 表 1（封闭信息抽取 F1）：无约束 LLaMA-33B 17.5，约束后 36.0，超过为该任务训练的 GenIE T5-base 34.8；约束模型精度与召回更均衡 [p.6]。
- 表 2（实体消歧平均准确率）：无约束 LLaMA-33B 54.1，IIG 68.2，IDG 80.3；监督模型 GENRE 88.8、ReFinED 89.4；约束的 33B 超过只用 AIDA 训练的 GENRE（80.0）[p.7]。
- 表 3（句法分析）：IDG 下 LLaMA-33B F1 54.6、合法率 100%，无约束 42.9 / 64.2%；专用方法 95% 以上 [p.7-8]。
- 延迟（表 4）：实体消歧与句法分析的 GCD 开销每 token 1 与 4 毫秒，可忽略；封闭信息抽取 69 毫秒 [p.8]。
- 似然错位：封闭抽取与句法任务里，无论模型大小，最可能的生成一律是空串；用长度归一化 α≥2.5 可修正；指令微调模型缓解但 Vicuna-13B 仍只有 46% 非空 [p.8-9]。
- 最佳实践：用更大的模型；语法越严格越好，尽量依赖输入；需要句法理解的任务不适合；有训练数据时微调小模型仍可能更好 [p.9]。

## 5. 作者陈述的局限
- 云端 API 不暴露解码过程时不能用 [p.10]。
- 语法规则极多（百万级）时增量解析的延迟上升 [p.10]。
- 句法类任务上远不及专用方法 [p.7-8]。

## 6. 原文摘录
- "Since API-based services such as OpenAI do not provide access to the distribution over the vocabulary, they cannot be used with GCD." [p.4]
- "Notably, LLaMA-33B beats GenIE T5-base (Josifoski et al., 2022), a state-of-the-art autoregressive model specifically trained for the cIE task on supervised data from the REBEL dataset (Huguet Cabot and Navigli, 2021)." [p.6]
- "Among the GCD-powered LLaMA models, we observe that IDG performs better than IIG, highlighting the benefits of using an input-dependent grammar." [p.7]
- "In the cIE and CP tasks, regardless of model size, the top generation is consistently an empty string" [p.8]
- "2. Grammars should be as restrictive as possible. Consider using input-dependent grammars." [p.9]

## 7. 对本库的可用点（笔记者推断）
- 本库用的是 API 模型，解码时的语法约束用不上；但"输出空间限制到输入里的候选"可以在程序侧事后做到同样的事：数值与日期字段的合法值只能是引文里出现的数与日期（依赖输入的"语法"），枚举字段只能是参数表的值，不合法即拒绝。这与 M11 的"值由程序从引文解析"是同一件事的两种说法。
- 本文的"最可能生成是空串"现象提醒：约束越严，模型越倾向给空答案。本库第 3 轮的推导值里"答不出"占多数（32 / 60），可能部分是这个效应；守则越严越要看空答率，并把空答与错答分开报。
- 结构的合法性与语义的正确性是两回事：本文保证前者；本库的 JSON 解析、类型校验已覆盖前者，第 3 轮里格式失败为零，所以改造的力气应放在后者。
