# M2 Manakul, Liusie, Gales, 2023. SelfCheckGPT: Zero-Resource Black-Box Hallucination Detection for Generative Large Language Models. EMNLP 2023, pp. 9004–9017
版本：published；M2_Manakul2023_SelfCheckGPT.pdf；第 1–9 页全读（方法、数据、结果、消融、局限），第 12–14 页附录略读（QA 变体的贝叶斯计数、提示模板、n-gram 与代理模型的补充表），参考文献略过

## 1. 问题与作者主张
- 作者称已有的事实核查方法要么需要输出概率分布（ChatGPT 这类系统拿不到），要么需要外部数据库；SelfCheckGPT 是不需要外部数据库、只用采样的黑盒方法 [p.1]。
- 核心假设：模型"知道"一个概念时，多次采样的回答相似且事实一致；幻觉出来的事实在随机采样下会发散、互相矛盾 [p.1-2]。
- 作者称这是第一个分析通用 LLM 回答的幻觉、且可用于黑盒系统的零资源方法 [p.2]。
- 作者称 SelfCheckGPT 在句子级幻觉检测的 AUC-PR 和段落级事实性排序的相关系数上都高于灰盒方法 [p.1]。

## 2. 方法
- 对同一查询再抽 N 个随机样本 {S1…SN}，衡量被评估回答 R 的每一句 ri 与样本的一致性，得到句子级分数 S(i)∈[0,1]，0 表示有依据、1 表示幻觉 [p.3]。
- 五个变体：BERTScore（句子与各样本中最相似句子的 BERTScore 均值取反）[p.4]；QA（MQAG：对句子生成选择题，分别在 R 和各样本上作答，统计不匹配数，附录 B 加贝叶斯与可答性软计数）[p.4]；n-gram（用样本训练 n-gram 语言模型，取句子的平均或最大负对数概率）[p.4]；NLI（DeBERTa-v3-large 在 MNLI 上微调，以样本为前提、句子为假设，只取 entailment 与 contradiction 两个 logit 归一化得到矛盾概率，再对样本平均）[p.4-5]；Prompt（问 LLM "Is the sentence supported by the context above? Answer Yes or No"，Yes→0、No→1、N/A→0.5，对样本平均）[p.5]。
- 段落级分数是句子分数的平均 [p.8]。
- 灰盒基线：生成模型自身的 token 概率与熵（Avg/Max 的 −log p 与 H）；黑盒代理基线：用 LLaMA 等开源模型近似 token 概率 [p.3]。

## 3. 数据与设置
- 数据：用 GPT-3（text-davinci-003）为 WikiBio 中 238 个概念生成维基百科式段落，共 1908 句；按主要不准确 / 轻微不准确 / 准确三类人工标注，分别 761（39.9%）、631（33.1%）、516（27.0%）句 [p.5]；201 句双标，Cohen's κ 为 0.595（三类）与 0.748（两类）[p.6]。
- 主回答 temperature 0.0、beam search；样本 temperature 1.0、N=20 [p.6]。
- Prompt 变体用 GPT-3 和 ChatGPT（gpt-3.5-turbo）作评估器；代理模型用 LLaMA-30B 等 [p.6]。
- 指标：句子级 AUC-PR（NonFact、NonFact*、Factual），段落级 Pearson 与 Spearman 相关 [p.7]。

## 4. 结果
- 表 2：随机基线 NonFact AUC-PR 72.96、Factual 27.04；GPT-3 自身概率 Avg(−log p) 为 83.21 / 53.97，段落级 Pearson 57.04 [p.7]。
- SelfCheckGPT：BERTScore 81.96 / 44.23；QA 84.26 / 48.14；Unigram(max) 85.63 / 58.47；NLI 92.50 / 66.08，Pearson 74.14；Prompt 93.42 / 67.09，Pearson 78.32、Spearman 78.30 [p.7]。
- 作者称 SelfCheckGPT-Prompt 明显优于灰盒方法与其他黑盒方法；unigram(max) 计算最便宜却在各设置下都不差，意味着在 N=20 个样本里只出现一两次的 token 很可能是非事实 [p.7]。
- 代理模型（LLaMA-30B 等）明显差于生成模型自身的概率，GPT-NeoX、OPT-30B 接近随机 [p.6]。
- 表 3：给外部参考文本（WikiBio 首段）时，NLI 与 Prompt 变体明显受益：WikiBio+NLI 为 91.18 / 48.14 / 71.61，Pearson 78.84；WikiBio+Prompt 为 93.59 / 65.26 / 73.11，Pearson 85.90；n-gram 变体反而大幅下降 [p.8]。
- 样本数增加，性能平滑上升、收益递减；n-gram 需要最多样本才到平台 [p.9]。
- 表 4：GPT-3 可以自检自己的文本，只用 4 个样本也比 unigram 好（Pearson 73.11）；ChatGPT 作评估器略好（N=4 时 76.47）[p.9]。
- 作者称 NLI 变体的表现接近 Prompt 变体，而 Prompt 计算量大，NLI 可能是最实用的折中 [p.8]。

## 5. 作者陈述的局限
- 238 段文本主要是 WikiBio 中的人物，需扩展到地点、物体等概念 [p.9]。
- 只在句子级判断事实性，而一句话可能同时含事实与非事实信息 [p.9]。
- 表现最好的 Prompt 变体计算量大，可能带来不切实际的成本 [p.9]。
- 作者在表 3 处说明，用外部知识就不再是零资源，且实践中不可能为每种用途都准备外部数据库 [p.8-9]。

## 6. 原文摘录
- "SelfCheckGPT leverages the simple idea that if an LLM has knowledge of a given concept, sampled responses are likely to be similar and contain consistent facts. However, for hallucinated facts, stochastically sampled responses are likely to diverge and contradict one another." [p.1]
- "Of the 1908 annotated sentences, 761 (39.9%) of the sentences were labelled major-inaccurate, 631 (33.1%) minor-inaccurate, and 516 (27.0%) accurate." [p.5]
- "This suggests that if a token only appears a few times (or once) within the generated samples (N=20), it is likely non-factual." [p.7]
- "As SelfCheckGPT with Prompt can be computationally heavy, SelfCheckGPT with NLI could be the most practical method as it provides a good trade-off between performance and computation." [p.8]
- "Third, in contrast, SelfCheckGPT with NLI/Prompt can benefit considerably when access to retrieved information is available." [p.8]
- "Our results in Figure 7 show that the performance of SelfCheckGPT increases smoothly as more samples are used, with diminishing gains as more samples are generated." [p.9]

## 7. 对本库的可用点（笔记者推断）
- 抽取边界的"读两遍、不一致即缺失"是本文思想的最简形式（N=2、二值）。本文的结论是样本越多越好、收益递减，且用 4 个样本已有可用的判别力；本库若要把"不一致"从二值改成分数，可按字段风险分级：金额、日期类读 3 遍，布尔类读 2 遍。
- 本库与本文设置的关键差别：本库的读取是对着固定段落做的，有"外部参考"（原文本身）。本文表 3 表明有参考文本时 NLI 与 Prompt 变体明显更强，而 NLI（DeBERTa-MNLI）不需要再调 LLM。可用点：读值之后加一道程序侧 NLI 核对——前提为引文段落、假设为"该字段的值是 X"的模板句，矛盾概率高则拒绝。这是不调用语言模型的第二道独立核验，适合 E 类自由文本字段。
- 本文的任务是开放生成，幻觉来自参数记忆；本库的错值来自读错文档中的量（比例当金额、注册资本当成本）。两者的采样一致性未必同样有效：系统性误读在两次采样里会重复（本库第 2、3 轮已见），所以采样一致性拦不住释义层面的错，释义与守则仍是主防线。
