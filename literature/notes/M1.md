# M1 Sainz, García-Ferrero, Agerri, Lopez de Lacalle, Rigau, Agirre, 2024. GoLLIE: Annotation Guidelines improve Zero-Shot Information-Extraction. ICLR 2024
版本：published（会议论文集 PDF）；M1_Sainz2024_GoLLIE.pdf；第 1–9 页全读（方法、数据、结果、消融、误差分析），第 21–22 页附录 C（无法解析的输出与幻觉标签）读，其余附录（示例格式、已见 / 未见标签、训练细节、效率、指南来源、数据污染）与参考文献略过

## 1. 问题与作者主张
- 作者称 LLM 加指令微调在信息抽取上落后于专用模型；信息抽取的标注指南含细粒度定义和大量例外，LLM 开箱不能遵循指南，此前即使最大的模型也失败 [p.1]。
- 作者称标签名不够：不同标注方案对同一标签的定义不同，复杂或少见的标签光有名字说不清 [p.2-3]。
- GoLLIE 是在少数已知任务上微调成"遵循指南"的 Code-LLaMA，作者称它能泛化到未见过的指南，零样本结果超过此前方法；消融显示详细指南是关键 [p.1]。
- 作者称 LLM 对任务标签的强先验会阻碍它遵循指南 [p.3]。

## 2. 方法
- 输入输出用 Python 代码表示：标签是 dataclass，指南写成 docstring，代表性候选写成注释，输入文本是字符串变量，输出是类实例列表，执行生成的代码即得结果 [p.3]。
- 训练正则化：类顺序打乱、类丢弃（只输出输入里定义过的类，减少幻觉）、指南改写、代表性候选抽样（每类固定池 10 个抽 5 个）、类名遮盖为 LABEL_1 之类 [p.4]。
- 骨干 Code-LLaMA 7B（另有 13B、34B 做规模分析），QLoRA，3 轮，批 32，学习率 3e-4 [p.5-6]。
- 指南取自各数据集作者发布的指南，没有的由人类专家按开发集写；候选来自指南或按词频从训练集抽；改写由 Vicuna 33B 自动生成 [p.5]。

## 3. 数据与设置
- 训练集主要是新闻与生物医学域的 12 个数据集，评测集取其他域（Twitter、网络安全、CrossNER 的 AI / 文学 / 音乐 / 政治 / 科学、科学制造、查询、维基）以保证零样本 [p.5]。
- 训练任务五种（NER、RE、EE、EAE、SF），只评测 NER、EE、EAE [p.5]。
- 比较对象：Instruct-UIE（不用指南）、PromptNER（用 GPT-3.5 加定义提示，不微调）[p.6]。

## 4. 结果
- 有监督（表 2）：基线平均 73.3±0.1，GoLLIE 73.0±0.3，差 0.3 F1，作者称这是预期的 [p.6]。
- 零样本（表 3）：全部数据集平均基线 42.3±0.2，GoLLIE 55.3±0.2（13B 56.0，34B 57.2）；与有 SoTA 的子集比，SoTA 平均 42.6，GoLLIE 58.4 [p.7]。
- 图 1：用指南提示 gpt-3.5-turbo 在音乐、政治域零样本 NER 约 20 F1 [p.2]。
- 消融（表 4）：去掉代表性候选 49.9（p 2.2e−10），去掉类丢弃 54.0（p 4.0e−3），去掉打乱 / 改写 / 遮盖无显著变化，全部去掉（基线）42.3 [p.8]。
- 已见与未见标签：所有模型在未见标签上略低，基线下降更明显，GoLLIE 差距更小，规模越大差距越小 [p.7]。
- 误差分析（表 5）：多义标签（MEDIA、VULNERABILITYPATCH、TRAILER、TASK）靠指南大幅改善（如 Trailer 0.0→76.4）；MultiNERD 的 TIME 标签模型按指南把年份标出而数据集未标；MISC、PLOT 这类模糊标签两者都差；科学家 / 作家与人的粗细冲突；政党被标成组织是训练数据带来的先验 [p.8-9]。
- 附录 C（表 8）：零样本数据集上无法解析的输出和未定义标签的幻觉都低于 1%（MultiNERD 49±11 / 32908 无法解析，51±8 / 67142 幻觉）[p.21-22]。

## 5. 作者陈述的局限
- 模糊或很粗的标签仍是难点；作者认为需要让模型遵循"总标最具体的类"之类的指令，并扩大微调数据集的数量与多样性 [p.9]。
- 对两个修改过的数据集（Ontonotes 5 缩减、TACRED 改为 SF），结果不可与 SoTA 直接比较 [p.5]。
- 训练与评测数据集之间总有标签重叠 [p.7]。

## 6. 原文摘录
- "IE tasks require more information than just label names, they require annotation guidelines." [p.2]
- "While there have been attempts to prompt LLMs using guidelines (Zhang et al., 2023a), strong prior knowledge of LLMs regarding task labels (Blevins et al., 2023) deter the model from adhering to those guidelines." [p.3]
- "In contrast, the representative annotation items give a stronger signal to the model. We see how definitions and representative candidates from the guidelines are complementary and help to improve each other." [p.8]
- "Surprisingly, years are not labeled as entities in the dataset. In this case, GoLLIE successfully follows the guidelines; unfortunately, the dataset annotations do not." [p.9]
- "In summary, we anticipate that GoLLIE will perform well on labels with well-defined and clearly bounded guidelines. On the other hand, ambiguous labels or very coarse labels pose challenges." [p.9]
- "As demonstrated in Table 8, for all the zero-shot datasets, both phenomena occur in less than 1% of the predictions." [p.22]

## 7. 对本库的可用点（笔记者推断）
- 本库给模型的字段释义加守则，就是本文的"指南"；本文消融说明指南里最有用的成分是代表性候选（例子），其次是定义。本库的释义目前只有定义，没有例子。可用点：字段词典加一列"原文怎么说"（如 cost_basis："at a total consideration of approximately RMB46.8 million"），取自已有案例的出处行，不用再写。
- 本文第 3 页的论断解释了本库的一类错：模型对"税率"的强先验（10% 预提）压过了释义（居民企业法定税率）。本文的对策是微调，本库没有训练数据；可用的替代是让守则直接点名先验（"不是预提税率"已这样写），并用两遍不一致和程序侧核对兜底。
- 本文的"数据集标注不合指南"一节提醒：本库评测的标准答案是人按出处写的案例，也可能与释义不一致；评测里模型"错"而释义"对"的情形（聚水潭的首次取得日）应回头修标准答案或释义，而不是只记模型错。
- 本文代码式输出解析失败率低于 1%，与本库用 JSON 非严格解析、解析失败即缺失的处理方向一致；格式问题不是主要风险。
