# Abstract interpretation: a unified lattice model for static analysis of programs by construction or approximation of fixpoints

## 1. 研究问题与作者主张

- 目标：作者要在统一的格模型中形式化程序的静态分析。作者称，抽象解释用程序对计算的表示去描述抽象对象全域中的计算，抽象执行的结果给出关于实际计算的信息；符号规则下，−1515 * 17 的抽象执行得到 (−)，证明该乘积为负 [p.1]。
- 作者认为所得概要一般 simple to obtain but inaccurate，结果 fundamentally incomplete，但可回答不需要完整执行知识或容忍不精确答案的问题，如忽略终止的部分正确性证明、类型检查、不确定可行时不进行的程序优化 [p.1]。
- 形式主张：抽象程序性质用 complete semilattice 建模；基本构件由 order preserving 函数局部解释，并给程序关联一个递归方程组；全局性质取该方程组的某个极端不动点 [p.1]。作者说明，满足其一致性条件的抽象解释与更精细解释的结果一致，特别可以证明与语言的形式语义一致；一致的抽象解释构成格，以此形式化抽象层次 [p.1] [p.5] [p.6]。
- 算法：作者称 Kildall [73]、Wegbreit [75] 等经典算法把程序性质算成有限 Kleene 序列的极限；序列无限时，文中提出有限的不动点逼近方法，并称其与抽象过程一致 [p.1]。
- 统一性：作者表示（It is our feeling）多数程序分析技术可理解为抽象解释，并称文中模型 'certainly the weakest which is necessary to unify these techniques' [p.13]。

## 2. 方法

作者的构造是形式化的，无实验设计。

- 具体语义：程序是 finite flowchart（Entries、Assignments、Tests、Junctions、Exits 五类节点），图假设连通 [pp.1–2]。语义取 Scott 与 Strachey 风格：Env = Ident° → Values，States = Arcs° × Env，确定性程序的 n-state 按节点类型给出下一状态 [p.2]；初始到最终状态的转移函数是 λF.(n-state ∘ F) 的最小不动点 [p.3]。
- 静态语义：弧 q 的 context C_q 是 P 的所有可能计算序列中可与 q 相联的 environment 之集，context vector Cv 给每条弧一个 context；Cv(r) = n-context(r, Cv) 构成 forward 方程组 Cv = F-cont(Cv)，Cv 是其最小不动点 [p.3]。作者取它为最具体的抽象解释 I_SS [p.1] [p.4]。
- 抽象解释：I = <A-Cont, ∪, ≤, ⊤, ⊥, Int>。A-Cont 是 complete ∪-semilattice（x ≤ y ⇔ x ∪ y = y），有上确界 ⊤，另假设有下确界 ⊥；context vectors（Arcs° → A-Cont）逐点构成 complete lattice [pp.3–4]。Int(r, Cv) 给出节点出口弧 r 的输出 context，假设 order-preserving；记 Int^(Cv) = λr.Int(r, Cv)，结果 context vector 可取为 Cv = Int^(Cv) 的极端解之一 [p.4]。
- 一致性（带 ' 的符号表示抽象侧）：借 abstraction α 与 concretization γ，要求 Cv ≤ γ(Cv') 且 α(Cv) ≤ Cv'（6.0）；假设 α、γ order-preserving（6.2），α(γ(x')) = x'（6.3），x ≤ γ(α(x))（6.4）；局部条件 6.5：具体输出 Int(a, CI) 被 γ(Int'(a, α(CI))) 包含，不要求反向包含。存在满足 6.1–6.5 的 α、γ 时记 I ≤(α,γ) I' [p.5]。
- 求值与逼近：Cv 由 elimination methods 或 Kleene 序列迭代（C := ⊥; until C = Int^(C) do C := Int^(C)）求得 [p.7]。序列无限时，作者给出 (i) 自 ⊥ 出发的递增逼近（ascending approximation sequence，AAS），A-Int^ 由 widening ∇ 局部构造 [pp.8–9]；(ii) 自上界出发的递减逼近（truncated descending sequence，TDS），D-Int^ 由 narrowing Δ 局部构造 [pp.10–11]；(iii) 它们的对偶方法 DAS、TAS [p.12]；∇、Δ 的条件见第 6 节。

## 3. 数据与范围

- 文中没有数据集、样本、实现或运行测量，内容为定义、论证和例子 [pp.1–13]。
- 对象：以 finite flowchart 表示的确定性程序（'language independent representation'）[pp.1–2]；形式语言只有上述五类节点。
- 法域、基准、被评测的模型：不涉及。

## 4. 结果

### 4.1 形式陈述与论证

- Cv 是 F-cont 的最小不动点；作者称容易举例说明 F-cont 的不动点不总是唯一，但 Cv 包含于 X = F-cont(X) 的任一解 [p.3]。
- 作者称 Int^ 易证 order-preserving，故有不动点 [p.4]；对 A-Cont 须为 complete semilattice 的要求，作者称 not drastic，依据 MacNeille [37] 的嵌入结果 [p.4]。
- 由 6.1–6.5，经 Appendix 的 T1（最大不动点）与对偶的 T2（最小不动点），得 6.0 [p.5] [p.15]；于是与 I_SS 一致的抽象解释与程序语义一致：任一执行中出现在弧 q 的 environment e 属于 γ(Cv'(q)) [p.5]。
- 作者说明，证明 I_SS ≤(α,γ) I_DS（演绎语义）后，该语义 gives a valid proof technique，'will never permit a false theorem to be deduced' [p.6]。
- ≤ 是 quasi-ordering；I ≡ I' 当且仅当有同构；识别等价者后得偏序；抽象 I_SS 的解释集是格，与 Contexts 上等价关系格的一个子集同构 [p.6]。
- 8.1：Int 为 complete morphism 时 Kleene 序列的极限 Cv 是最小不动点（例 Kildall [73]）；仅 continuous 时仍是（例 Wegbreit [75]）；仅 isotone 时 Cv 是最小不动点的近似（例 Kam and Ullman [75]）[p.7]。
- 8.2：求值终止当且仅当 Kleene 序列有限；作者列出 A-Cont 有限、长度有限 m、满足 ascending chain condition 等情形；无限序列可截断（得极限的下界），或借 induction principle、heuristics 过渡到极限或近似它 [p.7]。
- 9.1：存在有限 m 使 S_0 < S_1 < ... < S_m = S_{m+1}，S_m 是最小不动点的正确近似（上界）[p.8]；A-Cont 满足 ascending chain condition 时可取 A-Int^ = Int^ [p.9]；按 widening 构造的 A-Int^ 满足 9.1.1.1 与 9.1.1.2 [p.9]。
- 9.3：若 S_m 不是不动点且自 S_m 出发的递减序列有限，作者称其极限是比 S_m 更好的近似（'a better approximation'）[p.10]；截断递减序列是有限严格递减链，各项 'greater than' 最小不动点 [p.11]。
- 9.5：AAS 自 ⊥ 得最小不动点的上界，TDS 自 ⊤ 得最大不动点的上界，二者不对偶，其对偶 DAS、TAS 提供包围两个极端不动点的手段 [p.12]。

### 4.2 例子的输出

- 符号规则：−1515 + 17 的抽象执行得到论域中的第三个值（OCR 作 (f)），作者以此例说明概要 'inaccurate' [p.1]。
- 数据流与演绎语义：作者称数据流问题可形式化为抽象解释，available expressions 属 forward 方程组，live variables 与 very busy expressions 属 backward [pp.4–5]；演绎语义的 contexts 是谓词，n-pred 给出 Floyd [67] 的 strongest post-condition [pp.5–6]。
- 抽象层次例（单个整数变量）：区间 α(S) = [min(S), max(S)]；其上的进一步抽象可被不可比较的 I_CP（Kildall [73] 用于 constant propagation）与 I_RS（可用于符号规则）抽象，二者再被 I_R（可用于检查程序图中任一顶点是否从入口节点可达）抽象 [pp.6–7]。
- 性能分析（以各程序点假想计数器的终值描述性能，A-Cont 为加上上界 ∞ 的正实数格，用 Kirchhoff 流量守恒定律）：对 begin while T do I end，I 的执行次数取 n = 1 + q * n 的最小解（q 为 T 为真的概率），Kleene 序列 0 + 1 + q + q² + ... 是无穷级数，作者给出其和（OCR 中不可读）；Kleene 序列对应 Jacobi 迭代法（数值系数时）[p.8]。作者写 Kir 在固定概率下 clearly continuous，但不是 complete morphism [p.8]。
- 整数变量的界：用途是确保 PASCAL 数组下标在界内 [p.9]；对 x := 0; while true do x := x+1，Kleene 序列无限，⊥ < [0,0] < [0,1] < ... < [0,+∞]，作者称逼近序列的结果 somewhat inaccurate，但可在不确定时插入运行时下标检查 [p.10]。含 widening 的递增逼近给出 *C1 = [1,1]，*C2 = [1,+∞]，*C3 = [1,100]，*C4 = [2,101]，*C5 = [101,+∞] [p.10]；加入 narrowing 后 *C2 = [1,101]，*C3 = [1,100]，*C5 = [101,101] [p.12]。

### 4.3 否定性与有限性的陈述

- D1、D2 对 Cv 的定义在编译时不能直接使用：计算 Cv 实际上等于对全部可能输入运行程序 [p.3]。
- 作者写道，抽象解释一般 will not be powerful enough 去建立上述蕴含的逆（the reciprocal）[p.5]；并引 Manna and Shamir [75]：合适的解可能处于两个极端解之间 [p.4]。
- 作者写道 Ligler [75] 'shows clearly' I_SS ≤(α,γ) I_DS 的证明只在考虑 realizable Contexts、且程序只含 'clean' 基本构件（排除不终止、错误、副作用、标识符间共享等）时才能完成 [p.6]。
- 9.3.1：作者称选取 D 的刻画 very weak，因 D 可能被错误选取，且该刻画不提供 D 的有效构造 [p.10]。
- 区间例：作者称 widening 是 'a very rough operation'，同时指出 tests behave like filters；类 PASCAL 语言可先用声明中的界再 widening 到无穷 [p.10]。
- narrowing 例到达最小不动点，作者称 this is not the case in general；该 narrowing 只丢弃无穷界，不改进有限界 [p.12]。
- AAS、TDS、DAS、TAS 都可能给出并非所关心的不动点 fp，且不能把 fp 改进到 lfp 或 gfp；作者称需要 fixpoint improvement method [p.13]。

### 4.4 作者的解释或推论

- 作者列出可理解为抽象解释的技术（全局数据流分析、类型验证与发现、程序测试、符号求值、性能分析、语义形式化、正确性验证、归纳不变式的发现、终止性证明、程序变换，并附引用），称其有 'a fundamental unity'：给程序文本一个新解释，建立常为隐式的方程组；问题是验证用户给出的解是否正确，或发现、逼近这样的解 [p.13]。
- 作者称 ∩ 或 ∪ 在多数例子中表示路径汇合的效果是 'a pure coincidence'，该算子的真正需要是定义 completeness（保证 Int 有极端不动点）[p.4]。
- 作者称模型可为特定应用 considerably enriched，使 more powerful results 有可能得到 [p.13]。

## 5. 作者陈述的局限与前提

- 语言与语义前提：finite flowchart；确定性程序；<Nodes, Arcs> 连通；Junction 的直接前驱不是 Junction；Values 是 complete lattice [pp.1–2]。
- 抽象域前提：A-Cont 是 complete ∪-semilattice 且有 ⊥；Int order-preserving [pp.3–4]；α、γ 满足 6.1–6.4，局部条件 6.5 [p.5]。
- 作者称其抽象解释的定义有 completeness property（模型保证方程组有特定解，因而至少定义某个全局性质），并称还必须有 consistency property（只定义程序的正确性质）[p.5]。
- 性能分析假设 Prob(test(n) = true) 可由对输入数据的假设确定，作者称获得该概率是 main difficulty [p.8]。
- 逼近方法在最小不动点不可达时给出其上界 [p.8]；对 irreducible 程序图，widening 弧须作任意选择 [p.9]。
- 作者设想 'bound steps' 方法（AAS 等为 'separate steps' 方法），并称精度度量的定义需要 abstract contexts 的额外性质 [p.13]。

## 6. 关键术语

- abstract interpretation：用程序对计算的表示在抽象对象全域中描述计算，抽象执行的结果给出关于实际计算的信息 [p.1]；形式上是六元组 <A-Cont, ∪, ≤, ⊤, ⊥, Int> [pp.3–4]。
- consistent / refinement / abstraction：抽象解释与具体解释一致，指前者的 context vector 是后者的 context vector 的正确近似；存在满足 6.1–6.5 的 α、γ 时，I 是 I' 的 refinement，I' 是 I 的 abstraction [p.5]。
- syntactic / semantic abstract interpretation：前者参照程序语法证明正确（如 available expressions），后者须证明与语言形式语义一致（如 constant propagation）[p.5]。
- Kleene's sequence：⊥, Int^(⊥), ... 的递增序列，Int continuous 时极限是最小不动点 [p.15]；ascending chain condition 指 "every strictly increasing chain is finite, although not bounded" [p.7]。
- widening ∇ 与 W-arcs：∇ 满足 C ∪ C' ≤ C ∇ C'，且 S_n = S_{n−1} ∇ C_n 形式的无限序列不严格递增；W-arcs 是使方程组的每个 cycle 至少含一条的弧集，A-int 在其上取 Cv(q) ∇ Int(q, Cv) [p.9]。
- narrowing Δ：满足 C ≥ C' ⇒ C ≥ C Δ C' ≥ C'，且 S_n = S_{n−1} Δ C_n 形式的无限序列不严格递减；D-int 在 N-arcs 上取 Cv(q) Δ Int(q, Cv) [p.11]。

## 7. 原文摘录

- "A program denotes computations in some universe of objects. Abstract interpretation of programs con–sists in using that denotation to describe compu–tations in another universe of abstract objects, so that the results of abstract execution give some information on the actual computations." [p.1]
- "Despite its fundamentally in–complete results abstract interpretation allows the programmer or the compiler to answer ques–tions which,do not need full knowled~e of program executions or which tolerate an imprecise answer" [p.1]
- "Our formal definition of abstract interpretations has the completeness property since the model en–sures the existence of a particular solution to the system of equations ... It must also have the consistency property, that is define only correct properties of programs." [p.5]
- "In this example the widening is a very rough ope–ration which introduces a great loss of information." [p.10]
- "None of these methods can im–prove fp to reach f,fp or gfp, therefore a 'fix–point improvement method' is necessary. It is our feeling that such a method could be designed only when considering that A-Cent possesses a richer structure (i.e. for particular applications)." [p.13]
- "The mathematical model we studied in this paper is certainly the weakest which is necessary to unify these techniques, and therefore should be of very general scope." [p.13]
