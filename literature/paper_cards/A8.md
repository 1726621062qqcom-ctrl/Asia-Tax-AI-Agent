# A logic for default reasoning

## 1. 研究问题与作者主张

- 问题：在对不完整描述的世界进行推理时，如何形式化「没有相反信息时作出默认假设」这类推理。作者称默认推出的结论最好看作可能被后续观察修改或否定的 beliefs，这使任何 default 逻辑都是 non-monotonic [p.1]。
- 核心提议：default 被看作用来扩展不完整一阶理论的 meta-rules；一组 defaults 诱导出的 extensions 是关于该世界可持有的 beliefs 集合，一般不唯一 [p.7] [p.8]。作者认为这样的逻辑有两项任务：(1) 给出 extensions 的形式定义；(2) 给出 proof theory，对给定公式 w 判定是否存在包含 w 的 extension [p.7]。
- 作者的陈述：提出了任务 (1) 的定义；任务 (2) 对一般默认理论 'will turn out to be intractable'，因此限定于 normal defaults 并为之给出 proof theory；作者还报告一般情形下一个理论的 beliefs 不是 recursively enumerable 的 [p.7]。作者认为 normal defaults 涵盖范围很广的自然出现的默认，§1 的例子均属此类 [p.7]。
- 摘要列出的其余内容：对该类 defaults 发展出 'a complete proof theory'，说明如何与 top down resolution theorem prover 对接，并给出 'criteria under which the revision of derived beliefs must be effected' [p.1]。§6 具体陈述的是使已推出的 beliefs 仍属于某个共同 extension 的条件 [pp.33–35]；§7 推广到含自由变量的 open defaults [pp.35–49]。

## 2. 方法

- 形式框架：可数字母表的一阶语言 L；default 形如 α(x) : Mβ1(x),...,Mβm(x) / w(x)，α 为 prerequisite，w 为 consequent，M 读作 'it is consistent to assume'；default theory 为 (D, W)，D 是 defaults 集合，W 是 closed wffs 集合 [p.2] [p.8]。
- extension：作者先列出对 extension E 的三项要求：W ⊆ E；Th_L(E) = E；若 α ∈ E 且 ¬β1,...,¬βm ∉ E 则 w ∈ E [pp.8–9]。Definition 1 把 extension 定义为算子 Γ 的 fixed point：Γ(S) 是满足 D1–D3 的最小集合（D3：α ∈ Γ(S) 且 ¬β1,...,¬βm ∉ S 时 w ∈ Γ(S)），E 是 extension 当且仅当 Γ(E) = E [p.9]。Theorem 2.1 给出迭代刻画：E0 = W，E_{i+1} = Th_L(E_i) 加上 α ∈ E_i 且 ¬β1,...,¬βm ∉ E 的 defaults 的 consequents，E 是 extension 当且仅当 E = ∪E_i [p.9]。
- 立场：作者的立场是默认推理的目的是确定一个一致的 beliefs 集合（一个 extension）并在其中推理，证据迫使修订时再换到另一个 extension；因此 proof theory 面向 'believability'（是否有包含 β 的 extension），不是 theoremhood（β 是否属于所有 extensions）[p.14]。
- 范围收窄：normal default 为 α(x) : Mw(x) / w(x)；§§3–6 处理 closed normal default theories，§7 推广到含自由变量的 open defaults [p.15] [p.35]。
- default proof（Definition 3）：D 的有限子集的有限序列 D0,...,Dk，满足 P1：W ∪ CONSEQUENTS(D0) ⊢ β；P2：W ∪ CONSEQUENTS(Di) ⊢ PREREQUISITES(D_{i-1})（1 ≤ i ≤ k）；P3：Dk = ∅；P4：W ∪ ∪_{i=0..k} CONSEQUENTS(Di) 可满足 [p.19]。
- 与 theorem prover 对接：W 与各 default 的 consequent 取子句形式，consequent 子句以产生它的 default 为下标（indexed clause）；用 linear resolution 求证并返回所用 defaults；top down default proof 是一列 linear resolution proofs L0,...,Lk（Definition 4）[pp.26–28]。
- belief 修订：把已推出的 beliefs 作为 lemmas 并入 W，在 default support DS(P_β) 上加一致性条件（式 6.1、6.3）[pp.32–35]。
- open defaults（§7）：对 W 与各 default 作 Skolemization，Δ 的 extension 定义为 CLOSED(Δ) = (CLOSED-DEFAULTS(Δ), W) 的 extension，其中 CLOSED-DEFAULTS(Δ) 是各 default 的全部 ground instances（Definition 5）[pp.36–37]；再用 admissible proof sequence（Definition 8）与附加限制（Definition 9）定义 top down default proof [pp.41–44]。

## 4. 结果

**实证结果**

- 文中没有实验、实现或数据评测的结果；以下均为形式结果或作者的讨论 [pp.1–50]。

**形式结果与示例（按原文顺序）**

- §1 的表示：'most birds fly' 表示为 default BIRD(x) : MFLY(x) / FLY(x)，例外用一阶公式；作者指出，把例外全部列入前件的一阶表示无法对只知道是 bird 的 tweety 推出 FLY(tweety) [p.2]。作者称以默认表示 'most' 与 'few' 无需频率分布或模糊逻辑 [p.3]。
- 只含 default : MA / B 的理论中 B 可被相信，加入 ¬A 后 B 不能再被相信 [pp.5–6]。hometown 例：spouse 默认给出 Toronto，employer 默认给出 Vancouver，二者不能同时相信，作者写道可推出其一但不能同时推出两者 [p.6]。closed world defaults 作用于 p ∨ q 时有两个 complete extensions {p, ¬q} 与 {¬p, q} [p.7]。
- Examples 2.1–2.5 分别有 2、1、2、3、2 个 extensions [pp.10–11]。Example 2.5（D = {A : M(Ex)P(x) / (Ex)P(x), :MA/A, :M¬A/¬A}，W = ∅）的 extensions 为 Th({¬A}) 与 Th({A, (Ex)P(x)})，只有第二个相信某个体存在 [p.11]。Example 2.6（D = {:MA/¬A}，W = ∅）没有 extension [p.11]。
- Corollary 2.2：closed default theory 有 inconsistent extension 当且仅当 W 不一致；Corollary 2.3：此时它是唯一的 extension [p.11]。作者指出一般默认理论是 non-monotonic 的：(D, W) 有 extension E 时，(D ∪ D', W ∪ W') 可能没有包含 E 的 extension [p.11]。Theorem 2.4：extensions E ⊆ F 时 E = F [p.12]。Theorem 2.5：E = Th_L(W ∪ CONSEQUENTS(GD(E, Δ))) [p.12]。Theorem 2.6：E 是 (D, W) 的 extension 且 B ⊆ E 时，E 也是 (D, W ∪ B) 的 extension [pp.12–13]。
- 与 McDermott 和 Doyle (1978) 比较：作者把 default 映射为 modalized formula α ∧ Mβ1 ∧ ... ∧ Mβm ⊃ w，称 extensions 对应 fixed points [p.13]。作者指出所用算子不同：Δ = ({A : MB / B, C : MD / D}, {A ∨ C}) 有唯一 extension Th({A ∨ C})，对应的非单调理论有唯一 fixed point 且含 B ∨ D [p.13]。作者说 default logic 只在一阶框架内工作，defaults 为 meta-rules [pp.13–14]。作者评论 Kramosil (1975) 的 theoremhood 概念 'fails to capture a suitable intuitive interpretation of a default rule' [p.14]。
- Theorem 3.1：每个 closed normal default theory 都有 extension [p.15]。作者指出该定理对 McDermott 和 Doyle 的逻辑不成立，即存在没有 fixed point 的 'normal non-monotonic theories'；作者给出其所知最简的反例，含三个 normal defaults，该 closed normal default theory 有唯一 extension Th(W)，而对应的非单调理论没有 fixed point [p.16]。
- Theorem 3.2 (Semi-monotonicity)：D' ⊆ D 为 closed normal defaults 的集合，E' 是 (D', W) 的 extension，则 (D, W) 有 extension E，使 E' ⊆ E 且 GD(E', Δ') ⊆ GD(E, Δ) [p.16]；作者称它为 'a surprising and fortuitous result'，对任意默认理论不成立 [p.17]。Theorem 3.3 (Orthogonality)：closed normal 理论的两个不同 extensions 之并不一致 [p.18]。Corollary 3.4：W ∪ CONSEQUENTS(D) 一致时 extension 唯一 [p.18]。Theorem 3.5 的 Remark：增加 closed normal defaults 时 extensions 的个数 'monotone non-decreasing' [p.19]。
- Example 4.1（四个 defaults δ1–δ4）：{δ3}, {δ1,δ2}, {δ1}, {} 与 {δ4}, {} 是 D 的 default proofs；{δ3,δ4}, {δ1,δ2}, {} 满足 P1–P3 但不满足 P4，不是 D ∧ ¬E 的 default proof [p.20]。作者指出 default proof 的定义不是常规意义上的 proof procedure，没有给出确定 Di 的方法，也没有给出验证 P1、P2、P4 的方法 [p.20]。
- Theorem 4.3：β 有 default proof 则有包含 β 的 extension [p.21]；Theorem 4.7 为其逆，合起来为 Theorem 4.8：一致的 closed normal Δ 有包含 β 的 extension 当且仅当 β 有 default proof [pp.22–23]。作者指出此时仍没有计算上合理的求 default proofs 的方法，留待 §5 [p.23]。
- Theorem 4.9：closed normal default theories 的 extension membership problem（给定 Δ 与 closed wff β，是否有含 β 的 extension）不是 semi-decidable [p.24]。作者的论证：对 L 的 closed wffs 的递归枚举 w1, w2,...，取 Δ_i = ({: Mw_i / w_i}, ∅)，各 Δ_i 的 extensions 之并给出 closed 可满足 wffs 的集合；若任意 closed normal Δ 的 extensions 之并可递归枚举，则该集合可递归枚举，与其不可递归枚举矛盾 [p.24]。
- 可判定的情形：作者指出，若 W ∪ {α : (α : Mw/w) ∈ D} ∪ {w : (α : Mw/w) ∈ D} 属于一阶可证性的某个 decision class，则 extension membership problem 可判定，特别是 sentential 与 monadic 情形；一阶理论的 theorems 是 recursively enumerable 的，而作者说把 extensions 的元素视为 'theorems' 时，Theorem 4.9 表明它们不是 [p.25]。
- 搜索与 Theorem 5.1：top down 先选 D0 使 W ∪ CONSEQUENTS(D0) ⊢ β，再依次选 D1,...；bottom up 从检验 W ⊢ β 开始；作者转向 top down [pp.25–26]。作者写道 'It is not difficult to show'，借助 linear resolution 的完备性，β 有 default proof 当且仅当有 top down default proof（未给出证明细节）[p.30]；与 Theorem 4.8 合起来得 Theorem 5.1：一致的 closed normal Δ 有包含 β 的 extension 当且仅当 β 有 top down default proof [pp.30–31]。
- Examples 5.2–5.3：Example 4.1 的理论有两个 extensions，都含 D，Fig. 2 给出两种 top down default proof [p.28]。Example 5.1 的理论有三个 extensions，(Ex)G(x) 属于第三个，Fig. 3(a) 给出其 top down default proof [pp.27–28]。没有 extension 含 A ∧ (Ex)G(x)：对其 top down default proof 的尝试因 W ∪ CONSEQUENTS({δ1, δ4, δ2, δ3}) 不可满足而失败 [p.30]。
- Example 6.1：Δ0 = ({:MA/A, B:M¬A/¬A}, {A ⊃ B})，β0 = B 是其 derived belief；β1 = ¬A 是 Δ1（W 换为 {A ⊃ B, B}）的 derived belief，但不属于 Δ0 的任何 extension；作者以此说明把 derived beliefs 当 lemmas 的要求并非总能满足 [p.32]。
- Theorem 6.1：对 closed normal Δ0 = (D, W)，Δ_{i+1} = (D, W ∪ {β0,...,βi})，若 W ∪ ∪_{i=0..n} CONSEQUENTS(DS(P_{βi})) 一致（式 6.1），则 Δ0 有 extension E0 使 {β0,...,βn} ⊆ E0 [p.33]。(6.1) 不满足时，作者只给出方向：重新推出某个最小子集，否则舍弃某个最小子集 [pp.33–34]。Theorem 6.2：W 并上新事实集 F 后，类似的一致性条件（式 6.3）保证 (D, W ∪ F) 有包含 {β0,...,βn} 的 extension [p.34]。Theorem 6.3：增加 closed normal defaults 时，原有共同 extension 的 beliefs 仍有共同 extension [p.35]。
- §7：Δ 的 extensions 由扩展语言 L_{A∪Σ} 的 closed wffs 构成而非原语言 [pp.37–38]。对理论 {:MP(x)/P(x), (Ex)Q(x), ¬P(a)}，作者称 (Ex).Q(x) ∧ P(x) 在其 extension 中，而依 McDermott 和 Doyle 的 fixed point 定义似乎不在对应 fixed point 中，这 'suggests some fundamental differences' [pp.35–36]。Example 7.3（唯一 default P(x) ∨ Q(x) : MR(x) / R(x)，W = {P(a) ∨ Q(b)}）：Fig. 7(a) 是 (Ey)R(y) 的 admissible proof sequence，但该理论唯一的 extension 是 Th(W)，不含 (Ey)R(y)；作者写道 admissible proof sequence 'does not quite give us what we want'，须加以限制，得 Definition 9 [p.44]。
- Theorem 7.1：top down default proof 蕴含存在包含 β 的 extension [p.45]。Theorem 7.2：Δ 一致时反向成立，原文写 'We shall merely sketch a proof' [pp.47–48]。Theorem 7.3：一致的 normal Δ 有包含 β 的 extension 当且仅当 β 有 top down default proof [p.48]。作者写道对一般 normal default theories，§3 与 §6 的结果仍成立 [pp.48–49]。
- §8：作者写道可以证明 sentential wffs 的 minimal models 与 closed world assumption 所诱导 extensions 的 models 一致，并称这提示 closed world 默认理论与 circumscription 之间有更深的关系，但未能发现其具体内容 [p.49]。作者写道把 §7 的 proof theory 视为定义 PROLOG、PLANNER 类语言中否定语义的可能基础，'might be of some interest' [p.49]。
- 可满足性测试与 extensions 的选择：作者称可满足性测试带来 'A major computational problem'；作者设想的一种启发式是从 CONSEQUENTS(D') 对 W 做 forward chaining，超出时间或层数上限仍未导出矛盾则可考虑假定可满足，并写道这类启发式整体 'appears to be totally unexplored' [pp.49–50]。关于在竞争 extensions 间选择，作者提到静态优先级，并写道它在 hometown 例中 'seems not to work'，转而设想发现 discrepancy 时搜寻关于 Mary 的更详细信息来化解 [p.50]。

**作者的解释或推论**

- 作者认为一个不完整理论有多种扩展方式，这提示 default rules 可能是 nondeterministic 的，不同应用产生不同 extensions，即不同的 beliefs 集合 [p.7]；对 Example 2.5，作者指出不同 extensions 可支持不同的 ontologies [p.11]；作者认为非单调性要求为每个 belief 记录所作的默认假设，假设被推翻时撤回该 belief，并称 Doyle (1978) 的 Truth Maintenance System 是这类系统的 heuristic 实现 [p.6]。
- 作者认为 Theorem 3.2 使 proof theory 在所涉 defaults 上是 local 的，并称在大量 defaults 起作用时这是 'a very real computational advantage'；对 W 不能期待这种 locality [pp.17–18]。
- 对 Theorem 4.9，作者认为 P4 对 satisfiability 的依赖 'not merely an accidental feature'；作者据此认为任何默认的计算处理都须含启发式成分并偶尔得出错误的 beliefs，并写道考虑到人类常识推理的 'faulty nature'，这也许已是最好的期望 [p.25]。
- 作者认为不依赖 default 假设的 β 'have a much firmer status'：新增一阶事实时无需撤回，也不参与 belief revision [p.31]；称 Theorem 6.3 是 belief revision 方面 'the only truly comforting result'，并指出为 closed normal default theory 增加新 defaults 不影响旧 beliefs [p.35]。

## 5. 作者陈述的局限与前提

- 前提：一阶语言，D 与 W 至多可数无穷 [p.8]；作者称 consistency requirement 的形式定义 'perhaps the thorniest issue in defining a logic for default reasoning'，推到 §2 处理 [p.3]；top down 证明中假定 W 是子句集，称这 'with no loss of generality' [p.26]；§6 的出发点是 default reasoner 所持有的 derived beliefs 必须都属于某个共同 extension [p.32]。
- 范围：proof theory 只针对 normal defaults，任务 (2) 对一般默认理论 intractable [p.7]；作者写道他不知道有哪个自然出现的默认不能写成 normal 形式，并写道 closed normal 理论 'seems not to be a very interesting class'，但其结果将在 §7 推广 [p.15]。
- 局限：存在没有 extension 的默认理论（Example 2.6）[p.11] [p.14]；extension membership problem 不是 semi-decidable [p.24]；default proof 不是常规 proof procedure [p.20]；可满足性测试没有算法 [p.49]；bottom up 过程 'does not appear to be computationally very promising' [p.26]。
- 局限：derived beliefs 不满足一致性条件时的 belief revision 涉及 'quite complex issues which we do not address in this paper' [pp.33–34]；Example 6.1 表明 derived beliefs 并非总能当作 lemmas [p.32]。
- 局限：Theorem 7.2 的证明以 sketch 形式给出 [p.47]；bottom up 过程可由 default proof 的定义推出，细节 'We omit the details' [p.26]。
- 局限：没有 model theory [p.49]；与 circumscription 的关系未能确定 [p.49]；与 McDermott 和 Doyle 逻辑的关系 'appears to be complex' [p.14]；选择 extension 的方法未解决 [p.50]。

## 6. 关键术语

- default：形如 α(x) : Mβ1(x),...,Mβm(x) / w(x)，α 为 prerequisite，w 为 consequent；M 读作 'it is consistent to assume'；不含自由变量时为 closed default [p.2] [p.8]。
- default theory：'a pair (D, W) where D is a set of defaults and W a set of closed wffs'；每个 default 都 closed 时为 closed default theory [p.8]。
- extension：closed default theory (D, W) 的 extension 是算子 Γ 的 fixed point（Γ(E) = E），作者把它解释为关于世界可持有的一个 'acceptable set of beliefs'；GD(E, Δ) 为 α ∈ E 且 ¬β1,...,¬βm ∉ E 的 generating defaults [p.8] [p.9] [p.12]。
- normal default：形如 α(x) : Mw(x) / w(x) 的 default；所有 defaults 都 normal 的理论为 normal default theory [p.15]。
- closed world assumption：对某领域的全部关系 R 采用 closed world default : M¬R(x1,...,xn) / ¬R(x1,...,xn) 的推理 [p.4]。
- default proof 与 default support：Definition 3（条件 P1–P4）[p.19]；β 的 default proof P_β 的 default support DS(P_β) 是证明中调用的全部 defaults 之并 [p.22]。
- top down default proof 与 indexed clause：indexed clause 是子句 C 与 defaults 集合 D 的有序对 (C, D)；top down default proof 是一列 linear resolution proofs L0,...,Lk（Definition 4）[p.27] [p.28]。
- semi-monotonicity：Theorem 3.2 的性质，closed normal 理论增加 defaults 时，原 extension 可扩张为新理论的 extension [p.16]。

## 7. 原文摘录

- "In this paper we propose a logic for default reasoning. We then specialize our treatment to a very large class of commonly occurring defaults. For this class we develop a complete proof theory and show how to interface it with a top down resolution theorem prover." [p.1]
- "Inferences sanctioned by default are best viewed as beliefs which may well be modified or rejected by subsequent observations." [p.1]
- "Defaults therefore function somewhat like meta-rules; they are instructions about how to create an extension of this incomplete theory." [p.7]
- "In this paper we propose a definition for the first task. The second will turn out to be intractable for default theories in general. However, by focusing upon a special class of defaults called normal defaults, we can provide a proof theory." [p.7]
- "Every closed normal default theory has an extension." [p.15]
- "This extremely pessimistic result forces the conclusion that any computa- tional treatment of defaults must necessarily have an heuristic component and will, on occasion, lead to mistaken beliefs." [p.25]
- "Updating a closed normal default theory with new defaults cannot affect old beliefs." [p.35]
- "There appears to me to be no a priori reason for preferring Toronto over Vancouver, or vice versa here." [p.50]
