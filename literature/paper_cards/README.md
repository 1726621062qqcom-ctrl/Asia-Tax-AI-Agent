# paper_cards：论文卡片

每篇有文件的文献一张卡片，文件名 `<ID>.md`，共 67 张。卡片只转述论文本身：不评价，不联系本项目，不用清单里的“用途”。卡片由子智能体逐篇抽取，主智能体逐张验收。

## 1. 规则

```text
1. 只写论文里有的内容。不查网络，不补外部知识，不推测作者没写的东西。
2. 主张归属作者：写“作者认为 / 作者报告 / 作者假设”。保留原文的限定语（may、suggest、in our sample），不加强也不削弱。
3. 不用评价性词语，如：重要、开创性、突破、有力、令人信服、出色、新颖、缺陷、不足。引文里原有的词照抄。
4. 不提本项目、清单用途或读者自己的应用场景。
5. 结果写全：作者报告的负面结果、不显著结果、失败案例，和主要结果同样写。
6. 数字照抄，带单位和页码，不四舍五入，不换算。
7. 每条结果、每个术语都带页码：[p.N] 指 PDF 第 N 页（从 1 数，含封面页），跨页写 [pp.N–M]；
   B3 的更正一文写 [corr.p.1]。
8. 原文摘录逐字照抄 _work/text/<ID>.txt 里的文字，OCR 错误也照抄；每条不超过 50 个英文词，省略处写 ...；
   格式：- "原文" [p.N]。引文里的双引号改成单引号。
9. 原文没说清楚的，写“原文未说明”，不要猜。
10. 中文行文，术语保留英文原词。
11. 不写卡片作者自己的分析：不加总、不相除、不换算，不跨表比对得出新结论，不判断数字是否合理。
    原文自身两处印法不同，可以并列写出（“p.X 印为 A，p.Y 印为 B”），不作判断。
```

## 2. 结构

文件开头是 front matter，由 `tools/card_skeleton.py` 从 `_work/items/<ID>.json` 生成。抽取者只改 `read_scope`（`full` 或 `partial`）和 `card_status`（`draft` 改为 `filled`）；验收通过后由主智能体改为 `accepted`。

研究类（A–F 与 G5）八节，顺序固定：

| 节 | 写什么 |
|---|---|
| `## 1. 研究问题与作者主张` | 2–5 条：要回答的问题或目标；作者的核心主张，归属作者 |
| `## 2. 方法` | 形式化、模型、系统、算法、实验设计或实证策略，写到能看懂结果的程度 |
| `## 3. 数据与范围` | 数据来源、样本量、时期、法域、基准、评测的模型；不涉及数据就写明 |
| `## 4. 结果` | 每条带页码；数字照抄；正面和负面结果都写；分开“实证结果”和“作者的解释或推论” |
| `## 5. 作者陈述的局限与前提` | 只写文中说了的局限和明确假设，带页码；文中没讨论就写“文中未专门讨论局限” |
| `## 6. 关键术语` | 3–8 个，按文中定义转述或引用，带页码 |
| `## 7. 原文摘录` | 4–8 条逐字引文 |
| `## 8. 卡片说明` | 所用版本（发表版或预印本）、精读与略读的页、OCR 或图表问题、没覆盖的部分 |

官方文件类（G1–G4）七节：

| 节 | 写什么 |
|---|---|
| `## 1. 文件性质与目的` | 发布机构、文件类型、法律效力或地位、所述目的 |
| `## 2. 结构` | 章节、条款或附件的组织 |
| `## 3. 主要内容` | 主要规定、建议或标准，带条号和页码 |
| `## 4. 适用范围、生效与例外` | 适用对象、生效或实施日期、过渡安排、保留与例外 |
| `## 5. 关键术语` | 文件中的定义，带条号和页码 |
| `## 6. 原文摘录` | 4–10 条逐字引文 |
| `## 7. 卡片说明` | 同研究类第 8 节 |

## 3. 检查与验收

```bash
python literature/tools/check_card.py A1          # 一张
python literature/tools/check_card.py --all       # 全部
```

检查项：front matter 完整；各节齐全且没有“（待填）”；每条引文在所标页（前后各放宽一页）的文字里找得到，比较时只看字母和数字，OCR 断词不影响；结果节每条带页码；页码不超出 PDF 页数；不出现“本项目”等字样；评价性词语给警告。错误数为 0 才算通过。

验收由主智能体逐张做，结论记在 `ACCEPTANCE.md`：

```bash
python literature/tools/audit_cards.py A1      # 结果节与数据节的数字是否出现在所标页
python literature/tools/review_view.py A1      # 列出须人工读的部分：问题与主张、局限、卡片说明、不含数字的结果条目，并标出疑似卡片作者自行分析、评价性用语、未归属作者的条目
```

通过的卡片 `card_status` 改为 `accepted`。
