# Solving versus Verifying: Catching Contradictions in Tax Reasoning Systems

## 1. 研究问题与作者主张

- 要回答的两个问题（作者提出）：第一，当前 LLM 能否识别一个法律推理问题无法被可靠回答，原因是所需信息缺失（missing）或输入含逻辑矛盾（contradictions）；第二，模型在 solve 时没有识别出矛盾的情况下，让同一模型改为 verify 输入，它能否识别 [p.2]。作者称，现有 abstention benchmarks 主要测试 underspecification，真实法律输入也会因矛盾而出错，模型是否区分这两种失败模式尚未被探索 [p.2]。
- 动机（作者陈述）：作者称，在 LegalBench 的 SARA tax calculation task 上，近期模型对 well-formed inputs 有超过 90% 在 ±10% 内算对 [p.1]；作者认为真实法律输入常常缺少事实或事实相互矛盾，并在摘要中称 clean benchmarks 上的准确率对此时的模型行为 'says nothing'，在引言中称 well-formed inputs 上的准确率对此 'tells us little' [p.1]。
- 第一项主张（diagnosis）：作者认为高 benchmark accuracy 不能预测模型在含矛盾事实的输入上的安全行为。作者报告：对注入的矛盾，四个 high-accuracy 模型 solve 时 abstain 至多 15%（四个中三个低于 5%），63-76% 的情况下返回 clean-input answer，且没有输入 defective 的信号；让它们 verify 同样的输入，则标记其中 75-83% 的矛盾 [p.2]。作者另称，对 missing facts，这些模型几乎不返回 clean answer（preservation 低于 2%），所以对矛盾不 abstain 是选择性的（selective）[p.2]。
- 第二项主张（contradiction gate）：作者称，一次额外调用（让模型自己充当 input verifier，在其报告矛盾时 abstain）在六个模型上恢复 70-83% 的 contradiction abstention，clean-accuracy 成本为 0-5.1 个百分点（percentage points），无需 fine-tuning 与外部工具 [p.2]。作者写明 gate 是为检验检出的冲突能否转化为 abstention，不是作为部署系统提出的 [p.5]，并称它是简易的首道检查，不是完整方案 [p.10]。
- 与已有工作的区别（作者陈述）：作者称，所引的 abstention 研究集中在数学、一般问答与知识检索，对信息缺失下的法律推理关注较少；所引的 contradiction 研究在检索或文档层面，而本文的问题出在输入事实本身，并对比模型在两类缺陷下的行为 [p.3]。

## 2. 方法

- 总体设计：对 SARA 派生的税务案例施加两类扰动，比较六个 LLM 在三种条件下的行为：clean（未扰动）、redacted（删去一个必需的数值事实）、contradicted（为一个分类事实补充一个与之冲突的取值）[p.2]。同一模型被要求做两件事：solve（返回 tax liability 或 null）与 verify（标记缺失或矛盾的事实）[p.3]；verify 检查只在 contradiction 条件下评估 [p.2]。
- 扰动设计：redaction 针对数值事实，删去计算所需的一个非零数值（如纳税人收入），使问题无法回答，任何美元答案都没有依据；contradiction 针对分类事实，注入一条与原有事实逻辑上不相容的陈述，逐字插入描述中，与原事实至少隔一句，不含 hedging language [pp.3–4]。作者称这样配对，是因为每种扰动在对应的事实类别上产生清晰无歧义的缺陷：被删去的分类事实常可由上下文推断，两个冲突的数值读起来像更新或近似，而不像明确的矛盾 [pp.3–4]。作者的预期是识别出缺口或冲突的模型应 abstain [p.4]。
- 扰动生成：三个 LLM 辅助阶段，即抽取并分类事实（数值 vs. 分类）、确定性地选择要扰动的事实（redaction 取非零数值事实，contradiction 取有被支持的 contrary mapping 的分类事实）、改写案例文本以实施扰动；各阶段均用 GPT-5-nano (OpenAI)。矛盾句来自固定的规则表（例如 files jointly 对应 files separately），LLM 只改写其周围的文字 [p.4]。
- 验证：自动检查文本完整性（值已删除、无占位符、长度无膨胀、无 hedging language、无 prompt leakage、矛盾句逐字出现）；之后每个案例按固定标准人工复核，不合格者移除；对 contradiction，标准是注入句直接否定一个已陈述的事实，两者同时存在，且冲突与计算相关 [p.4]。随后一轮复核又移除 8 个 contradiction 案例，其注入句没有产生真正的冲突：一致的重述（如 does not file jointly 与 files separately 并列）、状态已被叙述蕴含（如 widow 或已完成的 divorce 配 not married）、注入 no dependents 而唯一的孩子属于另一纳税人 [p.4]。完整标准与验证代码在项目仓库 [p.4]；复核由谁执行，原文未说明。
- 被评测模型与调用：GPT-5 mini 与 GPT-5.2 (OpenAI)、Claude Sonnet 4.6 (Anthropic)、Qwen3.7-Plus (Alibaba)、Kimi K2.5 (Moonshot)、Gemini 2.5 Flash (Google)；GPT-5 mini、Kimi K2.5、Gemini 2.5 Flash、Qwen3.7-Plus 为 chain-of-thought（thinking）模型，GPT-5.2 与 Claude Sonnet 直接作答；Qwen3.7-Plus 与 Kimi K2.5 经 Fireworks AI 调用，其余经各提供方自己的 API [p.4]。调用时用结构化输出（JSON schema 把回答限制为一个可为空的数值字段），API 支持时 temperature 为 0；各模型取默认配置，不设模型特有的 thinking 参数；作者称有些模型的 thinking 无法关闭，所以 thinking 与 direct 的划分反映的是统一设置下的默认值；每个模型在完整数据集上评测三次 [p.5]。
- Prompt 与响应分类：模型收到适用法条、案例描述（clean、redacted 或 contradicted）和问题，被要求扮演 expert tax attorney，返回以 USD 计的 tax liability，若无法由所给事实确定则返回 null（完整 prompt 在项目仓库）[p.5]。作者有意把输出限制在这一选择上而不用自由文本：模型有明确的 abstain 方式，hedging language 无法遮蔽它是否检出问题；代价是看不到推理轨迹，只看到最终决定 [p.5]。响应分三类：Numeric (non-zero)、Zero（恰为 $0，视为有效的计算结果）、Absent（返回 null 或无可解析的数字）；只有 Absent 算作 abstention [p.5]。
- 指标：Baseline accuracy（clean 输入中答案在 ground truth ±10% 内的比例）；Abstention rate（扰动输入中返回 Absent 的比例）；Answer preservation（扰动输入中答案在 clean 输入 ground truth ±10% 内的比例，abstain 的案例记为未保持）[p.5]。作者称 abstention 是主要指标，preservation 是诊断指标，其余部分为 wrong-different（落在 ±10% 带之外的数）；对 clean 答案常常出错的 GPT-5.2 与 Claude Sonnet，作者称 preservation 意义较小，改为比较扰动输入与 clean 输入上的误差大小 [p.5]。
- Self-verification 与 gate：在另一次调用中，同一模型收到同样的法条、案例描述与问题，只被问事实是否足以回答且内部一致，不要求计算；响应限制为一个分类标签：none（输入 well-formed）、missing（缺少必需事实）、contradiction（两个事实冲突），同样用结构化输出 [p.5]。两条流水线：P0 是单独的 solver；P1 取 P0 的输出，但只要 verifier 返回 contradiction 就改为 abstention (null)；gate 有意只针对 contradiction，不对 missing 起作用，因为 solver 在 missing 上已经 abstain，在那里加 gate 会把两种效应混在一起；P1 比 P0 多一次模型调用，对 verifier 放行的输入不改变任何结果 [p.5]。Fig. 1 图注称 verify 调用与 solve 并行运行 [p.3]。对 gate 报告三个量：detection rate、false-flag rate、clean-accuracy cost [p.5]。verifier 与 solver 是同一个模型，每个模型的 verifier 也运行三次 [p.6]。
- 补充分析：把一个模型三次 solve 的结果当作 self-consistency ensemble，三次不一致就 abstain，与 verifier 比较；按 contradiction 类型拆分 verifier 的 detection rate，并给出 Wilson 95% 区间；汇总 verifier 在 contradicted、clean、redacted 输入上给出的标签分布 [p.8]。

## 3. 数据与范围

- 基础数据：LegalBench 中 SARA（StAtutory Reasoning Assessment）子集的 91 个税务案例；SARA 测试对美国 Internal Revenue Code 的 statutory reasoning，LegalBench 中的子集已按 benchmark 使用标准化；每个案例用自然语言描述纳税人的情况（收入、filing status、dependents、deductions）并询问 tax liability，ground-truth 答案由适用法条算出 [p.3]。
- 扰动后的案例：78 个 redacted 变体，取自 91 个源案例；少于 91 是因为人工复核排除了删除后答案仍被确定的案例（例如只剩零值字段）[p.4]。108 个 contradiction 变体，来自 91 个源案例中的 59 个，一个案例对每个符合条件的分类事实产生一个变体，因此单个案例贡献 1 至 5 个变体；按类别：marital status 49、filing status 38、dependent count 21 [p.4]。
- 示例（Table 1；问题 'How much tax does Alice have to pay in 2017?'，ground truth $6,621；各条件的输出为 GPT-5 mini 的回答）：clean 案例中 Alice 2017 年收入 $39,212、Bob 无收入，二人 2017 年 file separately，输出 $6,621；redacted 案例把收入写成 Alice had income，没有金额，输出 null；contradicted 案例在 file separately 之外又有 Alice and Bob file jointly in 2017 一句，输出 $6,621 [p.4]。
- 被评测的模型：六个，见第 2 节；每个模型在完整数据集上运行三次 [pp.4–5]。
- 法域与领域：美国 Internal Revenue Code [p.3]；作者称案例覆盖单一法律领域（美国联邦所得税）与单一 benchmark [p.9]。案例所涉的年份范围，原文未说明（示例为 2017 年）[p.4]。
- 数据公开：作者称数据集、扰动流水线、评测脚本和全部结果公开（Zenodo，https://doi.org/10.5281/zenodo.22329077）[p.3]。

- Solve 时对两类扰动的 abstain 与 preserve（Table 3，单位 %；三次均值，σ ≤4.2%，作者称 direct-answer 模型的 σ 最大；redacted n=78，contradicted n=108）[p.7]：

|---|---|---|---|---|

- Redacted 输入：没有模型返回 clean-input answer（preservation 至多 1.3%）；作者称模型 abstain 27-92%，或以较不安全的方式给出无依据的数或 $0 [p.6]。Qwen3.7-Plus 只在 27.4% 的 redacted 输入上 abstain；作者的脚注称 redacted 输入上 $0 的比例最高达 47%（Qwen3.7-Plus）[p.6]。
- Contradicted 输入（solve，P0），四个 high-accuracy 模型：abstain 率 Kimi K2.5 0.0%、GPT-5 mini 1.2%（σ=1.2%）、Gemini 2.5 Flash 4.6%（σ=0.8%）、Qwen3.7-Plus 14.8%（σ=3.0%）；四者在多数矛盾输入上返回 clean-input answer：76.2%（Gemini）、74.7%（GPT-5 mini）、67.6%（Kimi）、63.3%（Qwen3.7-Plus）[pp.6–7]。
- Contradicted 输入（solve，P0），两个 direct-answer 模型：Claude Sonnet 4.6 abstain 43.2%、preserve 7.4%；GPT-5.2 abstain 7.4%、preserve 22.5% [p.7]。作者称其在 contradictions 上的误差大小与 clean-input 误差相当（Claude Sonnet：median 0.282 vs. 0.271；GPT-5.2：0.218 vs. 0.189；原文未定义该度量，也未逐一标明两个数各对应哪种输入）[p.7]。
- Verify：让同一模型 verify 同样的 contradicted 输入，作者报告 verifier 标为 contradiction 的比例为 4 个 high-accuracy 模型 75-83%、2 个 direct-answer 模型 68-77% [p.7]；作者另称这高于四个 high-accuracy 模型 solve 时 0-15% 的 abstain 率 [p.7]。以 Table 1 的案例为例，GPT-5 mini solve 时在 contradicted 输入上返回 clean-input 的 $6,621；让它 verify 同一输入，它返回 contradiction，并写出该冲突："the facts state both that Alice and Bob file jointly in 2017 and that they file separately in 2017." [p.7]
- Gate（Table 4，108 个 contradiction 案例，三次均值，单位 %；Detect = contradicted 输入中被标为 contradiction 的比例；FalseFlag = clean 输入中被标为 contradiction 的比例；Abstain (P1) = 加 gate 后的 contradiction abstention，对照 Table 3 的 P0；Cost = gate 造成的 clean ±10% baseline accuracy 下降）[p.8]：

| Model | Detect | FalseFlag | Abstain (P1) | Cost |
|---|---|---|---|---|
| GPT-5 mini | 77.2 | 5.5 | 77.2 | 5.1 |
| Qwen3.7-Plus | 75.3 | 0.7 | 77.8 | 0.4 |
| Gemini 2.5 Flash | 79.9 | 0.0 | 79.9 | 0.0 |
| Kimi K2.5 | 83.0 | 4.4 | 83.0 | 4.0 |
| GPT-5.2 | 68.5 | 0.0 | 70.7 | 0.0 |
| Claude Sonnet 4.6 | 77.2 | 4.4 | 78.4 | 0.0 |

- Gate 的总体读数：作者报告 P1 把六个模型的 contradiction abstention 提高到 70-83%，P0 基线低至 0% [p.7]；对四个 high-accuracy 模型，contradicted 输入中以 clean-input 值作答的比例从 63-76% 降到 11-15% [p.7]；对两个 direct-answer 模型，verification 把 contradiction abstention 从 7.4% 和 43.2% 提高到 70.7% 和 78.4% [p.6]。
- Gate 的成本：false-flag 率为 0.0-5.5%；作者称在 capable models 中这是 real but modest 的 clean-accuracy cost：GPT-5 mini 5.1 points、Kimi K2.5 4.0 points，Gemini 2.5 Flash 与 Qwen3.7-Plus 基本为零（0.4）；两个 direct-answer 模型没有可测的成本，作者称部分原因是它们被误标的 clean 案例本来就答错了 [p.8]。
- Self-consistency 对照：把一个模型三次 solve 的结果当作 ensemble，三次不一致即 abstain，只标出 11-35% 的 contradictions（作者写 11-21% 对应 three strongest models、35% 对应 Qwen3.7-Plus；three strongest 指哪三个，原文未逐一说明），低于 verifier 的 75-83%；其 clean 输入上的 false-flag 为 3-14%，gate 为 0-5.5% [p.8]。作者说明六个模型中有四个在 temperature 0 下运行，所以三次运行之间的不一致反映的是非确定性而不是采样多样性，并称没有运行 nonzero temperature 的 resampling baseline [p.8]。
- Verifier 的标签分布（跨模型汇总）：contradicted 输入上，77% 标 contradiction、16% 标 missing、7% 标 none；clean 输入上，80% 标 missing（各模型 60-98%）、17.5% 标 none，contradiction 标签的 false flag 为 2.5%；78 个 redacted 输入上，各模型 95-100% 标 missing，0-4.7% 标 contradiction [p.8]。
- 按 contradiction 类型的 detection rate（Table 5，四个 high-accuracy 模型，单位 %，三次均值）[p.8]：

| Contradiction type | GPT-5 mini | Gemini | Kimi | Qwen |
|---|---|---|---|---|
| Marital status (n=49) | 83.0 | 78.9 | 82.3 | 77.6 |
| Filing status (n=38) | 94.7 | 94.7 | 97.4 | 97.4 |
| Dependent count (n=21) | 31.7 | 55.6 | 58.7 | 30.2 |

- 作者对 Table 5 的文字概括：filing-status 冲突 95-97%，marital-status 78-83%，dependent-count 30-59%（direct-answer 的 GPT-5.2 只有 6%）；dependent count 的 Wilson 95% 区间较宽，表注举例 GPT-5 mini 32% [16,53] [p.8]。作者称 filing 与 dependent 的差距在 Wilson 区间不重叠的意义上对抽样不确定性稳健，而 marital 与 dependent 的先后次序对 Gemini 与 Kimi 不稳健（dependent-count 检出率估计的约束很差，n=21），因此对这一对不下结论；各类型内的变体来自不同的源案例，只有 marital status 与 filing status 各有一个重复案例 [p.8]。对未被检出的 dependent-count 案例，verifier 返回 missing 多于 none，但 missing 也是它在 clean 输入上的主要标签，作者称标签分布在这一点上提供的证据很少 [p.9]。

### 4.2 作者的解释或推论

- 作者称，模型在 missing facts 上确实 abstain，所以它们对矛盾的行为是选择性的，不是一般的谨慎 [p.6]；并称模型在 solve 时 'largely ignore the contradiction and compute as if the conflicting statement were not present' [p.7]。
- 作者称，Claude Sonnet 与 GPT-5.2 的 abstain（Claude Sonnet 43.2%，GPT-5.2 7.4%）反映一般性的不确定，而不是有针对性的检测，依据是它们在 contradictions 上的误差大小与 clean-input 误差相当 [p.7]；作者对这两个模型只通过 P0 到 P1 的变化来解读 [p.6]。
- 作者称冲突在任务是检查输入时对模型是 legible 的，而 solving pipeline 从不询问；verification 步骤恢复了 solve 留着不用的检测能力 [p.7]。
- 作者称 verifier 不是一般的 well-formedness 判断者：SARA 的描述省略了严格的读者可能要求的事实（如 filing status、对收入的调整、itemised deductions、年龄与失明），verifier 的理由恰好引用这些；它作为 contradiction detector 起作用，是因为 contradiction 标签在 clean 输入上精确，而 gate 只作用于该标签；作者称 gate 能容忍 verifier 标签的不完美 [p.8]。
- 作者称类型间的次序与逻辑上的难度吻合：同一年 file jointly 与 file separately 是严格矛盾，has a child 与 no dependents 是 defeasible（孩子只有满足年龄与扶养测试才算 dependent）；dependent-count 检出率较低，部分是 verifier 正确地不把 defeasible 关系称为严格矛盾，而不只是漏检 [pp.8–9]。作者称不把全部漏检都读作检测失败 [p.9]。
- 作者称不确定 solve 为何漏掉矛盾；一种可能是 redaction 造成缺口，模型无法继续，而 contradiction 给出两个相互竞争的输入，模型每一步都有可用的东西，并可能通过默认取其中一个值自行化解冲突；无论机制如何，verification 步骤都恢复了漏掉的 abstention [p.9]。
- 作者称，在其模型集合中，逐步推理的模型是在 contradicted 输入上保留 clean-input answer 的模型（direct-answer 模型也返回数，但不复现 clean 值），与 AbstentionBench 报告的 reasoning-tuned 模型 abstain 更少的模式相符，但无法把 reasoning mode 与 capability 分开，故视为相符而非证实 [p.9]。作者称 contradiction 是 over-specified 而不是 under-specified，同样的模型对它没有检出，因此它是 underspecification benchmarks 没有隔离出来的另一种失败模式；作者称以默认取一个值的方式算过冲突输入，是 WikiContradict 在检索层面所见现象在输入层面的类比 [p.9]。
- 作者称，在其设定下，对 solve 任务重新采样不会暴露矛盾，而让模型检查输入会 [p.8]。作者称同模型 verifier 的数字是 verification gating 可恢复程度的下界：其他 verifier 可能更差，但同模型 verifier 仍是可选方案之一，因此在所有 verifier 选择上的最佳 gate 至少是作者所报告的水平 [pp.9–10]。
- 作者称高 benchmark accuracy 本身不构成模型在真实法律输入上行为安全的充分证据，因为真实输入中矛盾的客户信息很常见；作者称 gate 是几种方案中最简单的一种，upstream 输入检查、multi-agent disagreement、conformal ensembles、neuro-symbolic verification 等方案更重，但能抓到 gate 漏掉的 defeasible 冲突，所以作者把 gate 看作廉价的首道检查，不是替代 [p.9]。

## 5. 作者陈述的局限与前提

- 范围：作者称结果范围窄：SARA 派生案例相对真实税务输入是程式化的（stylised），真实输入的自然语言叙述含更多歧义与复杂性；只覆盖单一法律领域（美国联邦所得税）与单一 benchmark；missing 与 contradictory 的不对称是否推广到其他法律场景（合同分析、合规、刑事程序）是开放问题；限定于 SARA 是有意的选择，不是对所有法律 AI 的断言 [p.9]。
- 缺陷类型与事实类别绑定：每种缺陷只配一个事实类别，所以不对称是跨事实类别测得的，作者称没有把二者拆开 [p.9]；反向配对（对分类事实做 redaction、对数值事实做 contradiction）被作者描述为较不清晰 [pp.3–4]。
- Verifier 与 solver 是同一模型、同一权重：作者称这会带来相关的错误（correlated errors），共享的盲点可能让矛盾同时通过两个阶段 [p.6][p.9]；跨模型或外部 verifier 回答的是另一个问题，即检出能力能否由不同的模型恢复，本文没有测 [p.9]。
- 只看最终决定：因为输出被限制为一个字段，作者看不到推理轨迹；作者把记录推理轨迹以判断 solver 是否在内部检出冲突列为后续工作 [p.5][p.10]。
- 模型配置：默认配置，不设模型特有的 thinking 参数，有些模型的 thinking 无法关闭，thinking 与 direct 的划分反映统一设置下的默认值 [p.5]；作者称无法把 reasoning mode 与 capability 分开 [p.9]。
- Direct-answer 模型的 clean accuracy：作者称其较低的 clean accuracy 可能部分来自单一数字的输出格式，这给不在内部推理的模型留下很少的演算空间；作者称这不是解析问题，因为它们返回看似合理而错误的美元数，而不是 null；作者对其不做 prompt 工程以提高 baseline [p.6]。作者称对这两个模型 preservation 的意义较小 [p.5]。
- 统计：三次运行对方差是小样本 [p.6]；dependent count 只有 n=21，Wilson 区间宽 [p.8]。
- Verifier 标签不完美：在 clean 输入上 80% 标 missing，它不是一般的 well-formedness 判断者 [p.8]；dependent-count 检出最弱（6-59%），其中许多是 defeasible 而非严格冲突，需要严格处理时要更强的一致性检查 [p.10]；作者称更重的方法能抓到同模型 gate 漏掉的 defeasible 冲突 [p.9]。
- Self-consistency 对照：六个模型中四个在 temperature 0 下运行，不一致反映非确定性；nonzero temperature 的 resampling baseline 没有运行 [p.8]。
- 扰动生成器：GPT-5-nano 与 GPT-5 mini、GPT-5.2 同属一个提供方；作者称因为注入句由规则生成、逐字插入并经人工复核，不预期生成器偏向这两个模型 [p.4]。
- 明确的度量设定：答案在 ±10% 内算正确 [p.5]；$0 视为计算输出，不算 abstention [p.6]；只有 null 或无可解析数字算 abstain [p.5]。
- Gate 的定位：作者称它是为检验检出的冲突能否转化为 abstention，不是作为部署系统提出的 [p.5]；是简易的首道检查，不是完整方案或替代 [p.9][p.10]。
- 后续工作（作者列出）：在其他法律领域检验方法与 gate；记录推理轨迹；测试跨模型或外部 verifier；采用 neuro-symbolic、conformal 与 ensemble 等更强的 verifier [p.10]。

## 6. 关键术语

- clean / redacted / contradicted：三种输入条件。作者定义为 clean（未扰动）、redacted（删去一个必需的数值事实）、contradicted（为一个分类事实补充一个冲突的取值）[p.2]。
- Abstention（Absent）：模型返回 null 或没有可解析的数字；只有这一类算 abstention，因为 prompt 明确指示模型在选择 abstain 时返回 null；返回恰好 $0 算作有效的计算结果，不算 abstention [p.5]。
- Baseline accuracy 与 Answer preservation：前者是 clean 输入上答案在 ground truth ±10% 内的比例；后者是扰动输入上答案在 clean 输入 ground truth ±10% 内的比例，abstain 记为未保持；其余部分称 wrong-different（落在 ±10% 带之外的数）[p.5]。
- high-accuracy models 与 direct-answer models：作者把 GPT-5 mini、Qwen3.7-Plus、Gemini 2.5 Flash、Kimi K2.5 称为 high-accuracy models，把直接作答的 GPT-5.2 与 Claude Sonnet 称为 direct-answer models [p.6]。
- P0 与 P1（contradiction gate）：P0 是单独的 solver，输出模型返回的数或 null；P1 取 P0 的输出，但只要 verifier 返回 contradiction 就改为 abstention (null)；gate 只针对 contradiction，P1 比 P0 多一次调用 [p.5]。
- Verifier 标签：none（输入 well-formed）、missing（缺少必需事实）、contradiction（两个事实冲突）[p.5]。
- Detection rate、false-flag rate、clean-accuracy cost：detection rate 是 verifier 把 contradicted 输入标为 contradiction 的比例；false-flag rate 是 clean 输入被标为 contradiction 的比例；clean-accuracy cost 是有无 gate 时 clean 输入 ±10% baseline accuracy 之差 [p.5]。
- Strict contradiction 与 defeasible：作者称同一年 file jointly 与 file separately 是 strict contradiction，has a child 与 no dependents 是 defeasible，因为孩子只有满足年龄与扶养测试才算 dependent [p.8]；作者区分文本层面的保留标准（注入句直接否定一个已陈述的事实）与法律关系层面的 defeasibility [p.9]。

## 7. 原文摘录

- "The strongest models abstain when a fact is missing but compute through injected contradictions, returning the clean-input answer 63-76% of the time with no signal of the conflict; asked instead to verify the same input, they flag most of those contradictions." [p.1]
- "P0 is the solver alone: its output is whatever number or null the model returns. P1 is the contradiction gate: take the P0 output, but override it to abstention (null) whenever the verifier returns contradiction." [p.5]
- "On redacted inputs (Table 3) no model returns the clean-input answer (preservation at most 1.3%): models abstain on 27-92% of them, or less safely emit an unsupported number or $0." [p.6]
- "The verifier is therefore not a general well-formedness judge. It works as a contradiction detector because the contradiction label is precise on clean inputs (2.5% false flags) and the gate acts on that label alone." [p.8]
- "Under our setup, resampling the solve task does not surface the contradiction, while asking the model to check the input does; a resampling baseline at nonzero temperature could behave differently, and we did not run one." [p.8]
- "One possibility: redaction creates a gap, a step with no input, so the model cannot proceed, while contradiction provides two competing inputs, so the model has something to work with at every step and resolves the conflict on its own, likely by defaulting to one value." [p.9]
- "It is narrow in scope: the SARA-derived cases are stylised compared to real-world tax inputs, which involve natural-language narratives with more ambiguity and complexity, and they cover a single legal domain (US federal income tax) and a single benchmark." [p.9]
- "Detection is weakest on dependent-count contradictions (6-59%), many of which are defeasible rather than strict conflicts; where strict treatment is wanted, a stronger consistency check would be needed." [p.10]
