# Large language models as tax attorneys: a case study in legal capabilities emergence

## 1. 研究问题与作者主张

- 研究问题：作者考察 LLM 适用美国税法（tax law）的能力，比较三类因素：所用的 OpenAI 模型、是否向 prompt 提供相关法律文本（多种 retrieval 设置）、prompting 技术（chain-of-thought 与 few-shot）[pp.3–5]。三个实验问题：CoT 是否对所有（或大多数）模型与检索方法都一致地提高结果；更多、更相关的法律文本是否提高准确率；few-shot prompting 是否有帮助 [pp.5–7]。
- 选题理由（作者陈述）：评估 LLM 的法律分析能力有助于治理 LLM（Law-Informed AI / Law Informs Code 路径，作者称其前提是学习法律的精神可指导 AI 系统在新情境中作出合理选择）、提高法律服务效率、发现现行法律中的不一致 [pp.2–3]；选税法是因为法律依据集中于 Treasury Regulations 与 US Code Title 26 两处，许多规则有确定答案便于自动验证，解题需要逻辑推理与数学，且关系到公民和公司的经济生活 [p.3]。
- 核心主张（作者表述）：实验展示 emerging 的法律理解能力，每个后续发布的 OpenAI 模型表现更高 [p.1]；few-shot prompting 被发现能 significantly 提升 GPT-4 的表现 [pp.1–2]；LLM 结合 prompting 增强与正确的法律文本能达到高水平的准确率，但尚未达到专家税务律师的水平 [p.2]；LLM 自主推理法律的能力可能对法律职业与 AI 治理有 significant implications [p.2]。
- 方法上的主张：作者称其合成验证集全由新生成的问题构成，这些问题不在互联网上，不可能出现在任何 LLM 的训练集中，并称这是其评测有别于许多其他 LLM 评测之处 [p.3]。

## 2. 方法

- 题目生成 [p.3]：用 Python 代码随机生成选择题（一个问题加若干选项，仅一项正确），事实、名字和数字均随机。每题含：带选项的问题、正确选项、该选项为何正确的解释、可据以确定答案的具体法条引用。部分题只需定性理解（作者举例 checking-the-box 题），部分含算术（如计算 basis amount）；解答可引用 CFR 或 US Code。
- 考试结构 [p.3]：一套基于 CFR（三个 section），一套基于 US Code（四个 section）；每个 section 为 100 题，对应一种题型，共 seven 类题型。各类型内容在电子补充材料附录中，正文未列出。
- 评分 [pp.3–4]：按 LLM 是否选中正确选项评估。作者称手工评分 28 000 多道题不可行，模型输出格式又不一致，故用 GPT-4 完成最后一步评分的大部分：GPT-4 被指示把预测选项与真实选项比较。作者先在覆盖所有待测 LLM 的题目子集上核对该做法（脚注 2，见第 4 节）。
- 实验因素 [pp.4–5]：LLM（davinci、text-davinci-002、gpt-3.5-turbo、gpt-4）；检索设置（bypass_retrieval、similarity_search、gold_truth、lecture_notes）；是否使用 CoT；few-shot prompting（每题附三个其他问答示例，按题型匹配且不是评测题，不同时提供来源文档或讲义）；所有实验 temperature 为零。最终设置 mega_run 为 GPT-4 + gold_truth + few-shot + CoT。各设置定义见第 6 节，流程见图 1。
- 检索实现 [p.4]：similarity_search 用 Facebook AI Similarity Search 库建向量库，子节经 GTR-large 映射为 768 维 embeddings，取与问题余弦相似度最高的四个文档注入 prompt，并要求 LLM 返回所引子节的元数据。context window：davinci 为 2049 tokens；text-davinci-002 与 gpt-3.5-turbo 为 4097 tokens；gpt-4 为 8192 tokens；窗口较小时检索到的上下文有时被截断。完整的 prompt 模板示例在补充材料附录。
- 报告指标 [p.6][p.8]：图 2、图 3 说明称，各实验设置的准确率对不同题型子类取平均。

## 3. 数据与范围

- 数据 [p.3]：合成选择题，事实、名字、数字由 Python 代码随机生成；法律依据取自 Title 26 of the US Code 与 CFR 下的 Treasury Regulations。
- 题量 [p.3][p.5]：CFR 考试 3 个 section，US Code 考试 4 个 section，每个 100 题；实验总样本为 28 700 个 answers。每个设置的作答数原文未说明。
- 检索语料 [p.4]：法条与条例按子节（subsection）切成独立文档；CFR 向量库的文档平均约 130 tokens，US Code 向量库的约 250 tokens。所用法律文本的版本或获取日期原文未说明。
- 法域 [p.7]：作者写明实验限于 US tax law。
- 被测模型 [p.3][p.5]：OpenAI 的 davinci、text-davinci-002、gpt-3.5-turbo、gpt-4；作者称它们发布于过去三年间，各自发布时均为 state-of-the-art。具体 API 版本与调用日期原文未说明。
- 对照与时期：文中未报告人类律师的作答数据 [p.9]；实验日期原文未说明；稿件 Received 1 June 2023，Accepted 4 October 2023 [p.1]。
- 可得性 [p.1][p.12]：数据集在 GitHub（https://github.com/JohnNay/llm-tax-attorney/tree/main/data）；生成数据的代码可向合著者 Lawsky 邮件索取；电子补充材料见 figshare，doi:10.6084/m9.figshare.c.7031271。

## 4. 结果

本节只转述作者的文字描述与图说明；图 2–4 各点的数值正文未印出，卡片不从图中估读。

### 实证结果

- 模型：作者报告，对其他因素取平均后，使准确率一致上升的主要实验因素是所用的底层 LLM，CFR 题与 US Code 题均如此，新模型优于旧模型 [p.7]；图 4 说明文字称两套考试的总体答案准确率均随每个后续发布的 OpenAI 模型而清楚地上升 [p.8]。
- CoT：作者的问题是 CoT 是否对所有（或大多数）模型和检索方法都一致地提高结果，答案为 no，依据是图 2 中实线与虚线之差 [pp.5–6]；CoT 确实提高了 GPT-4 的表现 [p.6]，图 3 说明文字称这一提高见于不提供法律文本（bypass retrieval、few shot）和提供最相关法律文本（gold truth、mega run）两类设置 [p.8]。CoT 未带来提高的具体模型与检索方法，正文未逐一说明 [p.6]。
- 检索：作者的问题是更多、更相关的法律文本是否提高所有（或大多数）模型的准确率，答案为 weakly yes，依据是图 2 中部分线条向上倾斜 [p.7]；图 2 说明文字称，随着检索方法依次提供更相关的法律源材料，总体上可见准确率轻微上升 [p.6]。lecture_notes 的单独结果，正文未描述 [pp.6–7]。
- few-shot：对 GPT-4 的答案是 strong yes，对较弱模型似乎不那么一致地有用 [p.7]。
- 最高设置：图 3 说明文字称，GPT-4 的 mega_run 在 CFR 与 US Code 两套考试上均得到最好的总体准确率 [p.8]；图 4 说明文字称其表现远好于实验中任何其他设置 [p.8]。作者称 GPT-4 能利用相关法律文本与示例进行 reason，在较难的税法题上有很大比例答对（比例原文未给数值）[p.7]。
- 检索差距：作者在 Next steps 称，尤其对 GPT-4，输入 gold truth 文献比做 similarity search 带来 clear 的性能提升（该条针对 GPT-4，数值原文未给出；p.7 的 weakly yes 针对所有或大多数模型）[p.12]。
- 与专业律师：摘要称 LLM 尚未达到专家税务律师的水平 [p.2]；作者称最好的现有模型表现低于专业税务律师，后者预期能以 near-perfect accuracy 回答这些问题；文中未报告人类律师的实际作答 [p.9]。
- 评分核对（脚注 2）：作者称，在核对子集上 GPT-4 评分器对几乎所有题评分无误；对最旧、最弱的模型 davinci 中最含糊、最难评分的输出，仅在不到 1% 的情形出错；davinci 有时输出多个冲突选项，偶尔使评分器误判其选对；作者称这不够频繁，未对所报告的总体趋势造成 significant 影响，依据是对 davinci 评分的大量人工复核 [p.4]。
- 作答示例：作者给出两个 GPT-4（CoT）作答示例，说明评测数据的样子 [p.6]。示例 1：Aurora 以每股 `$15` 取得 20 股，设有 4 年的返还限制，2027 年归属时每股 `$23`，问雇主 Grasshopper 在 2027 年每股可扣除多少（10 个选项）；GPT-4 引用 §83(a)、§83(h)，算出 `$23−$15 = $8`，选 (5) `$8`，与正确答案一致 [pp.6–7]。示例 2：Zahra 的财产（价值 `$41 000`，basis `$33 000`）遗赠给 Dylan，Dylan 以 `$37 000` 售出，问其确认的损益（7 个选项）；GPT-4 取死亡时的公允市价 `$41 000` 为 basis，算出 `$37 000−$41 000 = −$4000`，选 (1)，与正确答案一致 [p.7]。两个示例所属的检索设置原文未说明。

### 作者的解释或推论

- CoT：作者认为 LLM 可能需要具备一定的能力水平，才能借助额外推理提高表现 [p.6]。
- 能力涌现：作者称，通过考察规模越来越大的模型，发现 emerging 的法律理解能力随每次模型发布而提高的证据，并称这 suggests 随着技术水平继续快速进步，可能出现 superhuman 的 AI 法律能力 [p.3]；其实验 suggest 法律理解可能是 emergent ability 之一 [p.11]；税法理解的 emergence 出现在 LLM 具备足够的底层通用能力、并被恰当 prompt 以引出 reasoning 行为之后 [p.9]。
- 检索差距：作者称该差距表明其 similarity search 技术和超参数默认值在相当大比例的时间里没有把最相关的 gold truth 来源送入 LLM [p.12]。
- 输入长度：作者提出一种可能（尚待分析）：LLM 的表现随输入变长而下降，故较大的 context window 不一定意味着填满最优 [pp.11–12]。
- 实务与治理：作者认为，LLM 若能复制熟练律师的大部分工作，可能 disrupt 法律服务业，但称不希望夸大这一可能 [pp.8–9]；LLM 可协助律师或提供初稿，可能降低法律服务成本、改善无力负担者获得法律咨询的机会，政策制定者可能需要重新考虑有关未经授权执业的规则 [p.9]；提升 LLM 法律分析的方法与 AI 治理相关 [p.9]；作者称没有 strong reason 认为 LLM 最终无法以更好的表现完成范围广泛的法律任务，并称其工作是追踪 LLM 法律推理进步的 benchmark [p.9]。

## 5. 作者陈述的局限与前提

- 范围：作者写明实验限于 US tax law，并称所考察的能力（找到相关法律依据并应用于具体事实情境）处于法律工作的核心，可能推广到其他法律领域（could be generalized）[p.7]。
- 与律师工作的差距：作者称最好的现有模型表现低于专业税务律师；回答明确的法律问题只是执业律师工作的一小部分；客户依赖律师提供情境化建议、伦理咨询和细致判断，现阶段 LLM 提供这些的一致性不如多数人类律师 [pp.8–9]。
- 评分与上下文：评分的最后一步大部分由 GPT-4 完成，davinci 的含糊输出偶尔误导评分器；窗口较小的模型，其检索上下文有时被截断 [p.4]。
- embeddings：GTR-large 的训练数据含生物医学与科学文本但不含法律文本，该检索用例对其是 out-of-domain；作者称正为后续工作开发 in-domain embeddings [p.4]。
- 检索：作者称 similarity search 技术及超参数默认值在相当大比例的时间里没有提供最相关的来源；计划试验 embeddings 选择、检索技术、向量库子节的 token 长度和放入 prompt 的子节数 [p.12]。
- 技术范围：作者只试验很简单的 prompting 与 augmentation 技术，更高级的方法留待后续 [pp.10–11]；其他后续方向有 prompt 长度与准确率的关系、自我反思与自我修正类 prompting、通用预训练 LLM 与专为法律推理预训练和微调的语言模型之间的比较 [pp.11–12]。
- 设定与前提：所有实验 temperature 为零 [p.5]；mega_run 被用来评估这些特定技术下的性能上界，gold_truth 被用来估计最佳检索的影响 [pp.4–5]；作者以选题理由的形式陈述：税法依据集中于两处、许多规则有确定答案，因而可用固定的文档全集并建立自动验证 [p.3]；作者称各被测 LLM 在发布时均为 state-of-the-art [p.3]。

## 6. 关键术语

- bypass_retrieval：基线设置，只给选择题与选项，不提供明确的法律上下文，评估 LLM 仅凭其 'internal knowledge base' 回答的能力 [p.4]。
- similarity_search：向 prompt 注入可能相关的法律文本：取向量库中与问题余弦相似度最高的四个子节文档 [p.4]。
- gold_truth：不用向量库，按每题附带的法条引用直接提供正确来源材料；作者称它估计 'theoretically best possible retrieval' 的影响，并可把不准确检索造成的错误与 LLM 推理错误分开 [p.4]。
- lecture_notes：以与该题型相关的课堂讲义（合著者 Sarah Lawsky 撰写）作为上下文 [p.4]。
- chain-of-thought (CoT) prompting：要求 LLM 逐步思考其回答 [p.4]。
- few-shot prompting：随待答问题给出三个其他问答示例，示例与题型匹配且不是评测题；few_shot 设置即 bypass_retrieval 加 few-shot prompting [p.5][p.7]。
- mega_run：GPT-4 + gold_truth + few-shot + CoT 的最终设置，作者称用于评估这些特定技术下性能的上界 [p.5]。
- emergent ability：作者的用法为，对一些需要复杂推理的任务，LLM 的能力在模型规模达到某一程度后以非线性方式 'emerges' [p.11]。

## 7. 原文摘录

- "The ﬁndings indicate that LLMs, particularly when combined with prompting enhancements and the correct legal texts, can perform at high levels of accuracy but not yet at expert tax lawyer levels." [p.2]
- "CoT does boost the performance of GPT-4, though. This suggests an LLM might need to have a certain capability level to be able to exhibit improved performance through additional reasoning." [p.6]
- "The answer is weakly yes, as evidenced by the upward slope of some of the lines in the charts of ﬁgure 2." [p.7]
- "The third experimental question is whether few-shot prompting helps. The answer is a strong yes for GPT-4 and seems to be less consistently useful for weaker models." [p.7]
- "The primary experimental factor causing consistent increases in accuracy, when averaged across the other factors, is which underlying LLM is being used." [p.7]
- "even our best current models underperform a professional tax lawyer, who would be expected to answer these questions with near-perfect accuracy." [p.9]
- "Our experiments suggest that legal understanding could be one such emergent ability." [p.11]
- "Especially for GPT-4, we saw a clear performance boost when feeding in the ‘gold truth’ legal documents, rather than performing similarity search to extract the relevant documents from a vector database." [p.12]
