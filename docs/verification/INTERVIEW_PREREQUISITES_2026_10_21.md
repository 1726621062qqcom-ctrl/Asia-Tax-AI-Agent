# 追问前提修复验收（2026-10-21）

## 发布范围

本次仅发布追问适用性、顺序、状态持久化和展示修复。main 继续使用 771e452 引擎及原有规则资料，不发布集成分支中的引擎升级。不修改计算公式、税率和上下界算法。

## 已识别并修复

- 从直接依赖改为检查完整前提链。即使中间字段已有“是”，更早的前提为未知或“否”时仍不能追问细节。
- 缺少前提时补问存在性问题；否定前提不再生成无关子问题；未知或暂缓不推断为否，不生成零值或批准意见。
- 同一字段被不同规则共用时按问题来源区别处理，避免用印花税减免条件阻止所得税规则的问题。
- 公司、资金流、年度和法域隔离。集团门槛不忽略成员冲突；方案中的可行性回答不覆盖明确事实或冲突。
- 税务手续的存在性回答单独保存，不进入计税事实；交易日期、持股或地区等核心信息改变后重新确认。刷新后保留回答。
- API 和聊天均校验前提，直接提交尚未解锁的子问题会被拒绝。策略版本参与结果指纹，旧结果不会继续授权旧追问。
- 新版引擎 251 个词典字段全部分类；加上兼容及基础输入共 256 项。新增的 59 项不再统一封禁：普通事实、条件细节、计算派生值和结构化资料分别处理。
- 5 个派生值需从原始事实计算，2 个按年度组织的亏损资料需结构化核对，明确展示原因，不能靠普通聊天批准或用单个数字替代。
