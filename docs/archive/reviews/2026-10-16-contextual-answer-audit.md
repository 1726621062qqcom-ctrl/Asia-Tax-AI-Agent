# 对话回答分支自查与修复

## 本次目标

用户指出：回答“个人”后系统只返回企业场景限制。检查范围扩展为聊天入口、路由提示、事实访谈、hybrid/legacy 执行、工具调度、检索回答、引用校验及前端展示；同时检查费用扣除与结构分析报告路径。结构分析报告继续是领域规则的可审计计算结果，没有将规则计算改成自由生成。

执行边界只决定能否调用某个工具，不能代替回答用户的问题。一般法规研究与个案分析分开；不支持个人个案分析时，仍可解释能力边界并继续查官方规定。

## 发现与处理

| 分支 | 原问题 | 本次处理 |
|---|---|---|
| 个人、非股息、其他地区的个案请求 | 同一句范围拒绝覆盖所有输入，访谈结束 | 根据已提供的主体、收入类型及地区解释具体限制；明确这不是税务结论；保留事实，允许更正、暂停或转为独立法规查询 |
| 从边界转查适用范围 | 简短选择丢掉“个人收款”上下文 | 由已知上下文补全查询，独立检索不继承个案期间和事实过滤；刷新后问题绑定仍有效 |
| 澄清问题 | 固定任务选择问题覆盖模型提出的具体澄清 | 保留简短且无具体税务判断的澄清问句 |
| agent 检索回答 | 模板加原文摘录，没有回答生成环节 | 使用已配置模型，结合当前问题、补全后的查询和明确关联的用户陈述解释获准入模的官方原文；普通来源查询不重新启动个案访谈 |
| 原文投影 | 固定截断 4,000 字符造成定义缺失 | 使用已验证、合同长度上限为 30,000 字符的完整获准文本；最多七份供解释，避免人为截断被误报为资料缺失 |
| 一般 FSIE 中文查询 | 缺少条款导航，原始关键词检索可命中无关条款并被全部排除 | 为一般 FSIE/境外股息查询补充既有适用范围条款导航；仍保留法域、主题及期间检查 |
| 无匹配、部分覆盖、校验失败 | 重复显示内部证据 ID 和诊断 | 对话中给出去重后的自然语言说明；原始诊断继续保留在检索元数据中便于排查 |
| 已有香港事实 | “香港”与“HK”字符串不同导致重复问地区 | 复用统一的地区适用性判断 |
| 事实汇总、缺口读取、冲突问题 | 暴露字段名、company、individual、unknown 等内部值 | 转换为用户可读的字段和状态；保留未知、冲突、未提供的不同含义 |
| 多任务/多次查询 | 结果拼接重复摘要、声明和引用 | 保留不同任务结果，对完全相同的段落去重，统一末尾引用；不做可能改变含义的语义删改 |
| 引用定位 | 一个父条款拆为多个显示片段，按证据 ID 建表时误用最后一个子条款标签 | 回答引用实际入模父条款的定位，不用任意最后一个显示片段替代 |
| 引用顺序 | 引用之后继续追加追问，或被 Markdown 合并进上一条列表 | 正文段落之间留空行；追问放在引用之前；agent、旧版资料回答和费用解释的引用均置后 |

## 回答生成与失败处理

- 只将检索层已验证且同时获准入模和展示的文本交给解释模型；展示许可不等于入模许可。
- 模型必须为每段返回证据 ID 和对应原文连续引文。程序验证 ID、文本归属与逐字引用，网址由检索结果提供，不能由模型自造。
- 引用存在并不证明推理一定正确；本次校验防止虚构/越权引用，不能替代税务专业判断。
- 无依据、资料仅获展示许可、模型失败或引用校验失败时不生成无依据替代答案，保留可核对的摘录或明确说明当前无法查证。
- 产品能力解释、事实澄清不冒充法律判断；没有可用法源时不为满足格式而补造引用。
- 保留事实冲突、确认、部分输出授权及最终复核门槛；不让个人场景进入企业规则引擎。
- hybrid 使用同一个 45 秒预算；真实模型回答最多六次模型调用（路由/调度与解释共享），其他路径原四次。搜索、读取和动作限制继续共享。无剩余资源时保留已完成结果。
