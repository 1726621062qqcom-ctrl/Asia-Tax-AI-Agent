# D-003 聊天研究 Demo 的数据与证据边界

日期：2026-09-21。依据：用户确认自主研发香港 FSIE 聊天研究 Demo 并要求进入目标模式完成。L0 专业状态不变，不依赖 Lexis API。

## 对 D-002 的限定补充

- 允许模型处理用户在界面明确声明的一般法律问题或虚构案例，以及版本化语料库内的 IRD 通用官方指引及香港官方法例原文。官方法律资料是引用上下文，不标成合成案件。
- 原有公开裁定 Case 68/72/74/75、客户资料和个人资料不进入本轮模型上下文；本轮语料装载器只接纳 `official_guidance` 和 `primary_legislation`。
- 不声称声明勾选能识别所有误填的真实资料。Demo 限受控本地研究，不部署给真实客户。
- 默认不开启外部模型。需设置既有模型连接项及 `FSIE_CHAT_ENABLE_MODEL=true`。密钥只在服务器环境，不返回浏览器、不存入报告或日志。
- 对话只存服务器内存，随机 HttpOnly 会话 Cookie，闲置一小时过期，最多 20 轮；新建/清空销毁旧会话，重启不恢复。模型供应商的数据处理条款仍按 D-002 未决事项管理。

## 来源与输出

- `chat_corpus.json` 是工程整理的官方指引与法例片段及中文研究提示，保留 URL/页面锚点/原文哈希/抓取时间/清单基线哈希。
- 本次新页面与清单基线有漂移；不覆盖原清单，不把抓取日期当法律有效期。基线覆盖截止仍为 2026-09-01，历史及未来时点须另核。
- 模型只能引用本轮实际检索返回的来源编号。浏览器链接由服务器语料库生成，不接受模型自造 URL。
- 存在性与原文哈希校验不等于法律蕴含校验。回答保持研究草稿；不能凭完整链接或模型一致性声称专家验证。
- 无模型或模型校验失败时，显式显示本地资料/回退模式，使用人工编写的研究提示，不伪装生成式回答。
