# 香港 FSIE 聊天研究 Demo

目标：用户在一个聊天框中描述虚构公司情况，查询法律依据、补充/更正事实、比较条件化合规安排，并获得逐段引用。默认本地单用户研究模式，不是税务专业意见。

## 本轮范围与验收

1. 咨询样本：法规解释、情况分析、筹划比较、纠错、范围外、未知法规、提示注入；不以 AI 一致性当税务准确率。
2. 资料：官方 IRD 指引和法例链接；来源类型、抓取时间、原文位置、哈希与法律覆盖截止分别保存。只使用可追溯的版本化片段，页面变更不自动更新批准知识。
3. 检索：中英关键词扩展与文本排序，按主题召回；无匹配不拼凑法律结论。
4. 回答：概览、事实、依据、可考虑路径、追问、参考资料；AI 输出必须使用检索返回的引用编号，引用校验仅保证存在与原文跨度，不声称证明法律推理正确。
5. 对话：服务器内存保存有限会话（随机令牌、到期与清空），事实保留用户原文和更正记录。重启即清空，不保存客户档案。
6. 界面：中文聊天页、示例、状态、事实侧栏、可展开原文引用、重试与清空；只绑定本地服务。
7. 数据：一般法律问题与用户明确声明的合成案件可进入已配置模型；公开官方通用指引允许作为引用上下文，公开裁定事实仍不发送，真实客户数据不在本轮授权范围。
8. 模型缺失：仍能使用明确标识的本地资料检索/固定研究提示模式；绝不伪装模型回答。接入模型后须另跑 live smoke，离线通过不等于模型质量通过。

## 五个核心对话

- 香港 FSIE 对境外股息有哪些规定？→ 制度范围、依据、必要条件。
- 虚构香港公司持有境外公司 60%，准备收股息，要交税吗？→ 不只凭比例判断，追问累算时间、收款路径、集团与实质。
- 有哪些合法税务筹划路径？→ 经济实质、参与路径、抵免和事先裁定的条件化比较；不鼓励虚假安排。
- 刚才说错了，分派的是股份不是现金。→ 更正已知事实，并重新分析收取路径。
- 日本消费税怎么处理？→ 明确范围外，不以香港资料回答。

## 本轮完成记录（2026-09-21）

- 本地 FastAPI 中文聊天界面、内存会话、候选事实/更正记录、关键追问、可展开原文引用与条件化研究路径已实现。
- 语料版本 `chat-corpus-0.2.0`：10 个 IRD 指引主题 + 7 组 Cap.112 法例原文。法例 XML 与原清单哈希一致；IRD 页面仍标记漂移及未专业验证。
- 默认本地资料模式；可显式启用现有兼容模型接口。两阶段模型路径、引用校验和失败回退已通过替身测试；并未实测供应商模型。
- 131 项离线测试通过，9 项原数据库/模型集成测试未运行；10/10 咨询行为场景、12 个合成抽取夹具、原知识包校验全部通过。
- 实际本地 HTTP 服务完成 5 轮对话与会话清空检查，返回正常；浏览器 JavaScript 语法检查通过，依赖检查无冲突。
- 浏览器控制工具因环境缺少 `CUA_REPL_ENABLED_SURFACES` 无法开启，因此未执行浏览器视觉/交互实测。可选 WebMCP staging 工具未在支持该标准的浏览器中验证，不影响普通聊天接口。
- 当前没有模型配置，真实开放式问答质量尚待连接模型后按运行手册演示场景复验。本地提示不冒充模型回答，不能用本轮离线结果声明税务准确率。
- 启动方式与数据边界见 `CHAT_DEMO_RUNBOOK.md`、D-003。本轮为本地研究交付，未对外部署、未接入 Lexis、未修改任何规则的专业验证状态。
