# 运行香港 FSIE 聊天 Demo

## 启动

在仓库根目录、Python 3.11+ 环境：

```sh
make venv
make install
make demo
```

已有 `.venv` 可直接 `make demo`。浏览器打开 http://127.0.0.1:8000 。只监听本地，不需要 PostgreSQL、不需要 Node，也不需要 Lexis 服务。

首轮先确认仅讨论一般法律问题或虚构案例，再输入问题。内置三个示例可以修改后发送。回答中的编号可展开官方原文，右侧显示候选公司事实。新建对话清空服务器会话，浏览器不使用 localStorage 保存案件内容。默认闲置一小时失效、最多 20 轮，服务重启后不恢复。

## 两种运行模式

**默认本地资料模式**：无需密钥，运行关键词检索、保守事实摘录、固定中文研究提示、追问和引用展示。它不具备通用模型的开放式理解能力，不把固定文字包装成 AI 生成。

**模型研究模式**：在本机 `.env` 配置：

```dotenv
FSIE_MODEL_BASE_URL=https://YOUR_PROVIDER/v1
FSIE_MODEL_API_KEY=YOUR_LOCAL_SECRET
FSIE_MODEL_NAME=YOUR_MODEL
FSIE_CHAT_ENABLE_MODEL=true
```

不要把实际密钥发进聊天或提交 Git。配置后重启 `make demo`，页面状态应显示“模型已连接”。复用已有兼容 Chat Completions 接口，每轮最多两个串行请求（规划/事实、检索后回答），每次超时最多 30 秒，无自动网络重试。接口或结构/引用校验失败会明确退回本地资料模式。页面状态不代表真实模型能力已通过验收。

未启用 `FSIE_CHAT_ENABLE_MODEL` 时，即使存在模型密钥也不会调用。缺少必需连接项时保持本地模式；`/api/config` 仅返回模式和资料元数据，不返回密钥、连接串或服务地址。

## 演示顺序

1. 问“香港 FSIE 对境外股息有哪些规定？”：查看指引、豁免路径和参考链接。
2. 新建对话，用内置“分析一笔境外股息”例子：查看持股、集团、形式等候选事实与缺失信息。
3. 补充“股息将在2025年累算，计划汇入香港账户”：观察事实变化与后续问题。
4. 说“刚才说错了，分派的是股份，不是现金”：确认分派形式更正并保留原描述记录。
5. 问“有哪些合法税务筹划路径？”：查看经济实质、参与、抵免及事先裁定等条件化路径。
6. 问“日本消费税怎么处理？”：应说明范围外，不套用香港资料。

本地事实摘录仅保留明确语句；未带明确更正词的不同描述会标为冲突。复杂或简短回答可能需要补全句子。模型模式可改善自然语言理解，但仍需逐项核实。

## 验证

```sh
make demo-check
make extraction-check
make check
make test
```

`demo-check` 为 10 个离线行为场景；`extraction-check` 为独立的 12 个事实抽取合成变体。它们不代表真实模型准确率。真实模型需启用后逐个重跑演示场景并检查引用是否支持论述、追问是否必要、更正后是否仍沿用旧事实。

## 数据、法律时间与引用

`chat_corpus.json` 保存了 10 个 IRD 通用指引主题片段及 7 组相关法例原文、中文工程研究提示、页面锚点、原文哈希及来源时间。原来源清单的覆盖基线为 2026-09-01；本次页面快照较新且存在漂移，未经法律变更审核。IRD 引用的网页锚点指向官方章节；法例引用来自与原清单哈希一致的 Cap.112 XML，显示条文定位和原文。界面明确区分法例和官方指引，尚不具备历史版本按时点查询。

`D-003` 明确允许通用官方指引及官方法例作为模型上下文，但不发送公开裁定原案及真实客户数据。不把更近的抓取日期视为法律有效期，也不声称完成历史法版本查询。来源存在、哈希正确及引用编号合法，均不等于法律解释已经专家验证。

语料更新：先在 `knowledge/hong_kong/fsie/raw/` 留存官方新快照，然后运行：

```sh
.venv/bin/python scripts/build_chat_corpus.py --snapshot PATH_TO_SAVED_OVERVIEW_HTML --statute-snapshot PATH_TO_CAP112_XML --output PATH_TO_CANDIDATE_CORPUS_JSON
```

该命令不联网、不修改原 source manifest；输出是工程候选版，需检查差异和研究提示后再替换启用语料。抓取时间取输入快照文件的修改时间，因此应保留真实下载文件及原始时间；不用于证明历史法律有效性。

## 运行边界

这是单进程本地 Demo。未实现多租户登录、案件持久化、真实客户准入、专家签字、生产限流或持续法规监控。运行时只有最后一轮请求成功后才写入会话；请求编号用于安全重试，重复请求不重复调用模型。不要将端口直接暴露到公网。
