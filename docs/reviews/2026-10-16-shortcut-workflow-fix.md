# 其余快捷入口的任务流程修复

日期：2026-10-16。

## 行为

延续境外股息咨询入口修复，将其余两个按钮从宽泛资料检索调整为明确的任务启动：

- 梳理事实：进入 fact_intake，复用现有访谈策略，询问当前缺失事实。已有事实继续使用，不将按钮文案写成案情。初次无案情时询问收款主体。
- 查阅依据：进入 reference_lookup，先询问具体问题、条文或官方案例编号；收到问题后使用既有路由与检索。这个澄清步骤不收集个案事实，也不将任务默认绑定个案。
- 更新中英文按钮填入的文案，兼容旧文案。入口提示必须与文案对应；用户编辑快捷输入后仍走普通对话。
- 保留事实冲突对依赖查询的阻断、事实确认和分析授权、问题版本验证及刷新恢复。

法规检索与引用展示沿用原实现；本次没有修复一般检索中的主题映射和诊断展示问题。入口澄清本身不作法律结论，因此不生成法规引用。
