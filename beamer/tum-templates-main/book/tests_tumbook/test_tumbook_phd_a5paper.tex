\chapter{Preface}
 {\color{TUMOrange}This is a Ph.D. thesis using the \emph{tumbook} class.
  It uses an \textbf{a5paper} layout with \textbf{6mm} bindingoffset and
  \textbf{times} as main text font. The coverpage is disabled, because
  it is intended to use a \emph{tumcover} for the printed thesis.\par
  The \emph{titlepage} contains the title information plus publisher.
  On a twosided layout, the backside of the titlepage contains
  the uppertitleback and lowertitileback.
  The next page is the official Ph.D. titlepage required by TUM. It is always
  printed in german and must contain exactly the content provided by this
  class. The next page contains the \emph{dedication}.\par
  After the \emph{preface} the \emph{table of contents},
  \emph{list of figures}, and \emph{list of tables} follow.
  The page numbering of the entire \emph{frontmatter} is printed as
  lowercase Roman numerals.\par
  The \emph{mainmatter} contains an example document with multiple chapters,
  sections, and subsections. The page numbering is printed in Arabic numbers
  always at the outer margin of the page. \textbf{times} is chosen as the
  main text font.
 }
